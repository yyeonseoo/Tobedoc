## 1. 배경과 목표

- **데이터**: DAIS-C (Discussing Abstract Ideas in Schizophrenia Corpus). 영국 영어 구어 면담 코퍼스이고, 조현병 환자군(CL) 15명과 비정신과 대조군(CO) 13명으로 구성된다.
- **목표**: 화자 조건부 few-shot 생성으로 합성 응답을 만들고, 그 품질을 4축으로 검증한다.
  - Fidelity: 분포 충실도와 CL/CO 효과 보존
  - Diversity: mode collapse 여부
  - Memorization: 원문 유출
  - Discriminability: 실제/합성 판별 가능성
- **공통 원칙**
  - 합성 데이터에는 항상 synthetic 라벨을 붙이고, 실제/합성을 섞은 파일을 만들지 않는다.
  - seed를 고정하고(42), 설정은 `config.yaml` 하나로 관리하며, 프롬프트·응답을 모두 로그로 남긴다.
  - 단계마다 `reports/`에 기록한다.

## 2. 데이터 탐색과 전처리 (공통 기반)

### 2.1 확인한 사실
- 원본 위치는 `./data/`가 아니라 `DAIS-C-Annotated-Upload/`이다. 파일은 123개다 (docx, rtf, txt, pdf, xlsx, sav).
- 원천 파일은 **태그가 포함된 speaker-only 파일**로 정했다. 21AN11과 21UN11의 `_Raw.txt`는 FULL 대화 파일과 맞지 않는다 (21AN11은 약 절반이 빠졌고, 21UN11은 다른 텍스트가 섞인 것으로 보인다).
- 태그는 논문 Table 1로 확인했다.
  - `<INT>` 면담자, `<InAu>` 청취 불가, `<An>` 익명화, `<Lh>` 웃음 등
  - 저자 주석 태그: `<Gr>`, `<WS>`, `<TC>`, `<DT>`, `<FL>`
- **구두점이 없다.** 문장은 spaCy가 의존 구문 분석으로 추정한 분절이다.
- 전체 턴의 65.6%가 30단어 미만이다. 그래서 "응답" 단위를 ≥30토큰 턴으로 정했다 (실제 688개: CL 493, CO 195).
- 18UG10은 실질 응답이 0개라 생성에서 제외했다.
- **그룹과 주제가 교란돼 있다.**
  - CO 13명 중 10명은 "How was the experiment?"(심리언어 과제 소감)로 면담을 시작했다.
  - CL 15명 중 14명은 창의성 질문으로 시작했다.
  - 따라서 하류 분석에는 주제 층화가 필수다.

### 2.2 전처리 (`src/preprocess.py`)
- 태그를 제거했다. 빈 태그는 통째로, 범위 태그는 태그 표시만 지웠다.
- spaCy `en_core_web_sm`으로 문장을 나누고, 3토큰 미만 문장은 인접 문장에 병합했다.
- 산출물: `data/processed/corpus.parquet` (턴 1,923개, 토큰 90,483개).

## 3. 검증 체계 (세 시도 공통, `src/validate.py`)

| 축 | 지표 |
|---|---|
| Fidelity | 표면 피처 9개(길이, 문장 길이, MATTR, 품사 비율, filler)와 SBERT 의미 피처 2개(인접 문장 유사도 `adj_sim`, 첫 문장 대비 거리 `first_dist`). KS 검정과 Wasserstein 거리. **CL−CO 효과 보존 검사**(Cohen's d, BH 보정) |
| Diversity | 합성 간 pairwise 코사인 유사도, distinct-1/2 (크기를 맞춘 부트스트랩), 준중복, 시드 화자 수렴도 |
| Memorization | 5-gram overlap (기준선: 실제 응답이 다른 화자와 공유하는 비율), 임베딩 최근접 이웃 거리, 상위 overlap 샘플 육안 확인 |
| Discriminability | TF-IDF(1–2gram) + 로지스틱 5-fold CV AUC와 상위 피처 |

**선고정 임계값** (2차 생성 전 커밋 `599a33b`, 판정 코드 `src/judge.py`):

| 축 | 합격 | 주의 | 불합격 |
|---|---|---|---|
| Fidelity | 실제에서 유의한 차이 중 방향 일치 ≥6/8 | 4–5 | ≤3, 또는 가짜 효과(실제 비유의·합성 유의)가 1개라도 있음 |
| Diversity | 준중복 0이고 \|Δ pairwise cos\| ≤ 0.05 | ≤ 0.15 | 그 밖 |
| Memorization | overlap/기준선 ≤ 1.5× | ≤ 2.5× | 초과 |
| Discriminability | AUC ≤ 0.75 | ≤ 0.85 | > 0.85 |

## 4. 1차 시도: 자가 생성 few-shot

- **방법**
  - 화자당 5–8문장 연속 구간 2–3개를 시드로 쓰고, 화자 안에서 구간 조합이 겹치지 않게 순환했다.
  - 목표 길이는 화자의 실제 응답 길이 분포에서 뽑았다.
  - 사용자 지시로 API는 쓰지 않았고, Claude가 같은 템플릿으로 직접 작성했다. temperature는 명목 라벨일 뿐이다.
- **진행**: 파일럿 17개 → 미리보기(비유창성 부족, MATTR 과다 진단) → 본 생성 95개.
- **치환 정책을 이 단계에서 정립했다.**
  - 원본에서 1명만 쓰는 희귀어(accidie, apotropaic 등)는 치환했다.
  - 2명 이상이 쓰는 **프로토콜 자극어**(boomerang, edge, salty, opinion 등)는 원어를 유지·복원했다.
  - 고유명사와 개인정보는 화자 수와 무관하게 항상 치환했다.
  - `ingest`가 최종 텍스트로 준수 여부를 자동 검증한다.
- **결과**: AUC 0.940.
  - 판별 단서: `erm` 과용, quite/actually 같은 정제된 표현, `er`·단어 반복 부족.
  - 합성 CL에 **실제에 없는 topic drift 과장**이 생겼다 (first_dist d=0.48, adj_sim d=−0.34).
  - 시드의 특징적 구절을 복사한 사례가 있었다.
- **방법론적 한계**: 임계값을 결과를 본 뒤 정했고, 생성자·검증 코드·판정이 같은 세션에서 나와 독립성이 없다.

## 5. 2차 시도: 프로파일 조건화 + 사후 필터 (선고정 임계값)

- **Step A**: 화자별 비유창성 프로파일을 측정했다 (`src/profile_speakers.py`). er/erm/기타 filler, 즉시 반복률, 절단어, 문장 길이, MATTR.
- **Step B**: 프롬프트에 시드 화자의 측정 수치를 명시했다. 특정 단어를 금지하는 지시는 넣지 않았다.
- **Step C**: 사후 필터 (`src/post_filter.py`).
  - 그룹 실제 분포의 5–95 백분위를 벗어나거나, 시드와 6-gram이 일치하거나, 1차 코퍼스와 6-gram이 일치하면 탈락.
  - 탈락하면 다시 쓴다 (최대 3회 시도, 그래도 실패하면 결번).

**주요 사건 (있는 그대로)**
1. **앵커링 발견 → 전량 폐기.**
   - 생성자가 1차 출력을 근접 패러프레이즈하고 있었다.
   - 처음에는 파일럿을 보존하고 "다른 주제 각도"로 다시 쓰려 했으나, 사용자 지시로 철회했다.
   - 파일럿 포함 전량을 폐기했다. 시드는 1차와 겹치지 않는 윈도우로 교체했다 (79% 샘플이 1차 시드와 문장 중복 0).
2. **파일럿 r1 중단.** 첫 시도 탈락률이 58.8%로 50%를 넘었다. 시드 구절 복사가 원인이었다.
   - 사용자 승인으로 템플릿 두 가지를 보강했다: "다른 말로 다시 서술" 지시, filler 하한 규칙.
3. **템플릿 보강 후 파일럿 r2**: 탈락률 23.5% → 전체 진행.
4. **시드 중복 예시 버그.** 23CT18_00 프롬프트에 같은 예시가 두 번 들어 있었다.
   - 넓게 고치는 방식은 이미 생성된 파일럿 프롬프트까지 바꿔서 폐기했다.
   - 조합 선택 단계에서만 중복을 막는 좁은 수정으로 고쳤다. 전수 재검사 결과 중복 0, 바뀐 프롬프트는 23CT18 4건뿐이었다.
5. **생성자의 필터 회피 시도 2건.** 문장 길이 지표를 낮추려는 마침표 삽입과 상투 표현 회피였다. 둘 다 적용 전에 되돌렸다.
6. **시드 복사 6-gram 분류** (사용자 요청): 98.1%가 시드 화자 고유 구절이었다. 상투 표현 때문에만 탈락한 시도는 1/52였다.
7. **프라이버시**: 원문 n-gram이 기록되는 리포트를 git 추적에서 제외했다.

**결과**: 100개 (CL 50 / CO 50), 결번 12.

| 축 | 결과 | 판정 |
|---|---|---|
| Fidelity | 방향 일치 6/8, 가짜 효과 0 | 합격 (단, first_dist d=0.483은 그대로이고 q=0.075라 경계) |
| Diversity | 0.054 | 주의 (0.004 차이). distinct-1/2는 실제 구간을 넘어 **어휘 다양성 과잉** |
| Memorization | 1.44× | 합격 |
| Discriminability | AUC 0.932 | 불합격 |

- 판별 단서: "erm and" 식으로 절을 잇는 습관, 과제 주제어 밀착, 실제의 `it it`·`sort of`·`yeah` 부족.
- 통화 관련 어휘(signal, network 등)는 상위 피처에 없었다 (가장 높은 것이 618위).

## 6. 3차 시도: OpenAI API 실제 샘플링 (최종)

### 6.1 외부 전송 결정
- 3차는 원본 익명 전사 발췌가 든 프롬프트를 OpenAI로 보낸다. 그래서 근거를 확인하고 기록했다.
- **데이터 출처**: 원본 7z의 다운로드 기록상 UK Data Service **ReShare 855021** (DOI 10.5255/UKDA-SN-855021).
  - 라이선스: **CC BY-SA 4.0**
  - 접근: "Accessible to: Anyone (open access data)"
- **동의서**: "(Optional) I consent to the (permanent) archiving of my (anonymised) data, via the UK Data Service, so that it may be used in other studies and/or by other researchers."
- **반대 방향 문구도 기록**: 참여자 설명서의 "Your data will be anonymous to everyone outside of the research team."
- **사용자 결정**: 전송 진행. 근거는 ① CC BY-SA와 Anyone 공개, ② 동의서의 보존·타 연구자 사용 항목, ③ 이미 공개된 익명 발췌만 전송.
- **OpenAI 정책 (호출 전 확인)**
  - API 입력은 기본적으로 학습에 쓰이지 않는다.
  - 남용 모니터링 보관은 30일이다. Zero Data Retention은 OpenAI 사전 승인이 필요해 적용하지 못했다.
  - **모든 호출에 `store=False`를 명시**했다.
- **부수 발견**: 라이선스가 CC BY-SA이므로, 출처를 표시하고 같은 라이선스를 따르면 합성 데이터도 재배포할 수 있다. 1–2차는 "라이선스 미확인, 재배포 금지"라는 보수적 가정으로 진행했다.

### 6.2 방법
- gpt-4o (`gpt-4o-2024-08-06`), temperature 1.0, 호출마다 랜덤 seed, `store=False`. 누적 지출 $5에 도달하면 멈추는 하드 리밋을 두었다.
- 프롬프트: 2차 프롬프트에 한 문단만 추가했다 — 절 중간의 즉시 반복, 중도 재시작, 얼버무림(sort of, kind of)을 넣으라는 지시.
- 필터·치환 감사·검증·판정은 2차 코드를 수정 없이 썼다.
- 버그 수정 1건: 래퍼에서 `validate.py`가 import 시점에 인자를 읽는 문제를 피하도록 했다.
- 탈락분은 **같은 프롬프트로 다시 뽑기만** 했다 (재작성 없음).

`um`/`uh`는 이 코퍼스 전사 규약(er/erm)에 없는 표기다. 프롬프트가 "fillers written as er / erm"을 요구했는데도 나왔다.

## 7. 종합 결론

### 7.1 개선된 것
1. **암기·원문 유출**: overlap 3.48× → 1.44× → 0.80×. 최장 공유 구간 15 → 8 → 7단어.
2. **가짜 그룹 효과**: 1차 3개 → 2·3차 0개.
3. **합성 CL의 topic drift 과장**: 자가 생성(1·2차)에서는 d=0.483으로 그대로였다. 다른 모델의 실제 샘플링(3차)에서 처음으로 0.194로 줄었다. 1·2차의 과장은 프롬프트보다는 **생성자(Claude) 자신의 "조현병 발화" 고정관념**에서 왔을 가능성이 있다 (비교가 한 번뿐이라 단정은 못 한다).
4. **추적성**: 임계값 선고정, 폐기 이력, 프롬프트 전수 재검사, 치환 감사, 외부 전송 근거, 비용 로그를 모두 남겼다.

### 7.2 한계로 남은 것
1. **판별 가능성은 세 번 모두 불합격이다.** 길이로는 구분되지 않는다 (AUC 0.48–0.57). 매번 **어휘 수준의 문체 습관**이 드러났다.
   - 1차: 지나치게 정제됨
   - 2차: 연결어 습관과 어휘 다양성 과잉
   - 3차: 비유창성 과잉
2. **지시를 하나 더하면 그 지시가 과잉 이행된다.**
   - "다른 말로 다시 써라"(2차) → 어휘 다양성 과잉
   - "비유창성을 넣어라"(3차) → 비유창성 과잉
   - 지시는 방향은 바꾸지만 **양**은 맞추지 못한다.
3. **응답 단위 범위 필터는 코퍼스 단위 과잉을 못 잡는다.** 모든 샘플이 상한 근처에 몰려도 각각은 통과한다.
4. 데이터 구조의 한계는 그대로다: 그룹-주제 교란, 소수 화자(27명, 두 화자가 응답의 큰 비중), 응답 단위 검정의 비독립성.
5. **합성 CL은 LLM이 모방한 발화일 뿐 임상적 실체가 아니다.** 진단 근거나 증상 지표의 대리 변수로 쓸 수 없다.

### 7.3 더 시도해 볼 만한 것이 있는가
**같은 방식(LLM에 지시를 더하거나 다듬기)을 계속하는 것은 권하지 않는다.** 세 번의 결과가 보여주듯, 지시를 고칠 때마다 다른 쪽으로 넘쳐서 수렴하지 않는다.

**메커니즘을 바꾸는 방법은 남아 있다.** 다만 모두 "4차 시도"가 아니라 별도 연구 설계에 해당한다.

| 방법 | 핵심 | 기대 | 위험·비용 |
|---|---|---|---|
| **분포 맞춤 선택** | 지시는 고치지 않고 후보를 많이 뽑은 뒤(예: 슬롯당 10개), **코퍼스 전체의 빈도 분포**(filler, 얼버무림, 반복, n-gram)가 실제와 맞도록 부분집합을 고른다 | 양을 지시가 아니라 선택으로 맞추므로 과잉 이행을 우회할 수 있다 | 판별기·지표에 과적합될 위험. 선택에 쓰지 않은 **홀드아웃 판별기와 홀드아웃 화자**로 평가해야 한다. API 비용은 수 달러 수준 |
| **결정적 후처리 정규화** | um→er, uh→erm 같은 전사 규약 위반만 기계적으로 고친다 | 규약 위반 단서가 사라진다 | 빈도 과잉 자체는 남는다. "가공"이므로 보고 의무가 있다. 단독으로는 부족하다 |
| **소형 모델 미세조정** | 실제 전사로 언어 모델을 직접 학습해 분포를 배우게 한다 | 지시를 따르는 게 아니라 분포를 학습한다 | 코퍼스가 약 9만 단어(CL 약 6만)로 너무 작다. **암기 위험이 매우 크고**, 원본으로 학습한 모델을 다루는 데이터 거버넌스 문제가 생긴다 |
| **증강하지 않기** | 실제 데이터만으로 화자 단위 교차검증, 주제 층화, 효과 크기 보고 | 타당성 위험이 가장 적다 | 표본 수 한계는 그대로 |

**권고**
- 이번 연구 범위(지시 기반 조건부 생성)는 **여기서 종료**하는 것이 타당하다.
- 증강이 꼭 필요하다면 다음 연구는 **"분포 맞춤 선택 + 홀드아웃 평가"**를 새 프로토콜로 선고정하고 시작하는 것이 유일하게 해볼 만한 방향이다.
- 하류 분석이 목적이라면 합성 없이 실제 데이터로 화자 단위 검증을 하는 편이 결과 해석이 깨끗하다.

### 7.4 선행 연구 기준으로 다시 채점하면 합격인가 (2026-10-02 추가)

"선행 연구들은 판별기를 쓰지 않는 관대한 기준으로 성공을 보고했고, 그 기준으로 채점하면 우리 3차도 합격"이라는 해석이 제기됐다. 이를 원문 확인과 직접 측정으로 검증했다.

**선행 연구 원문 확인**

| 연구 | 확인된 사실 | 판별기 | utility 평가 |
|---|---|---|---|
| DAIC-WOZ 우울증 증강 ([arXiv 2411.17672](https://arxiv.org/abs/2411.17672)) | 원본 전사를 요약(synopsis)+감성 분석으로 바꾼 뒤, PHQ-8 점수 조건으로 변형 생성. "A total of 309 synthetic data samples were generated by creating three variations for each original transcript". BERT 예측 RMSE: 실제 5.59 → 합성 단독 4.80 → 실제+합성 4.64 | 없음 | **있음** (핵심 성공 근거) |
| 정신과 평가 보고서 합성 ([arXiv 2604.27014](https://arxiv.org/html/2604.27014v1)) | 스페인어 **서면** 임상 보고서를 ICD-10 조건으로 생성. MMD·BERTScore·Self-BLEU·TTR·최근접 거리(표절 d<0.05)로 평가 | 없음 | **없음** (향후 과제로 명시) |

- 우울증 논문은 요약으로 바꾼 이유를 직접 적었다. "the generated transcripts often include irrelevant elements such as breaks, stuttering, repetition, and off-topic conversations … the generated transcripts closely mimic the original data". 즉 **구어 전사를 직접 생성하는 길을 시도했다가 피한 것**이다. 우리가 정면으로 부딪힌 문제가 바로 이것이다.
- "판별 가능성을 기준으로 쓴 연구가 거의 없다"는 **위 임상 텍스트 증강 두 편에는 맞다.** 그러나 합성 데이터 평가 전반으로 넓히면 과장이다. 표 형식 합성 데이터에서는 판별 점수가 표준 지표다 (SDMetrics LogisticDetection = 로지스틱 회귀 + 교차검증 ROC-AUC, 우리 3d와 같은 설계).

**직접 측정** (`src/prior_criteria.py` → `reports/07_prior_criteria_rescore.md`)
- Utility 설계: 과제는 응답 단위 CL vs CO 분류다 (선행의 점수 예측에 대응).
- 화자 단위 층화 그룹 5-fold를 10회 반복했다. **테스트는 학습에 없는 화자의 실제 응답만** 쓰고, 테스트 화자를 시드로 한 합성은 학습에서 뺐다.

| 기준 (출처) | 1차 | 2차 | 3차 | 해석 |
|---|---|---|---|---|
| **Utility: 실제+합성 vs 실제 단독**, 응답 AUC 변화 (2411.17672) | −0.002 / −0.001 | −0.003 / −0.004 | **+0.003 / +0.004** | (TF-IDF / SBERT) 3차만 소폭 개선(10회 중 6·8회)이지만, 반복 간 표준편차(0.013–0.03)보다 훨씬 작다 → **의미 있는 개선 없음** |
| **Utility: 합성 단독 학습(TSTR)** | −0.10 / −0.10 | −0.10 / −0.09 | −0.20 / −0.10 | 합성만으로 학습하면 실제 단독보다 확실히 나쁘다. 선행 연구는 합성 단독이 실제보다 나았다 |
| **Fidelity: MMD** (2604.27014) | 0.023 | 0.018 | 0.072 | 실제를 반으로 나눈 기준선 0.0037보다 5–20배 크다. 선행은 기준선 없이 "근접"으로 판단했다 |
| **Privacy: 표절률** (최근접 거리 < 0.05) | 0% | 0% | 0% | 통과 |
| **Privacy: 평균 최소 거리** (2411.17672) | 0.351 | 0.363 | 0.375 | 실제→실제 0.413보다 가깝다. 선행 논리("멀수록 안전")로는 약간 불리하지만 표절 수준은 아니다 |
| Diversity: TTR | 0.686 | 0.752 | **0.655** | 실제 0.618에 3차가 가장 가깝다 |

**결론**
- **"선행 기준이면 우리도 합격"은 절반만 맞다.**
  - Privacy(표절)와 우리 Fidelity(효과 보존)는 통과한다.
  - 그러나 **우울증 논문의 핵심 성공 근거였던 utility에서 우리 합성 데이터는 의미 있는 개선을 만들지 못했다.** 합성 단독 학습은 실제보다 명확히 나쁘다.
  - 분포 거리(MMD)도 실제 기준선과 비교하면 가깝지 않다.
- 단, 우리 과제에는 **천장 효과**가 있다. 실제 단독 AUC가 이미 0.87–0.90이다 (그룹-주제 교란으로 과제가 쉽다). 그래서 개선 여지가 작았다. 선행처럼 불균형하고 어려운 회귀 과제였다면 결과가 다를 수 있다. 이것은 검증하지 않은 가설이다.
- **선행과의 차이에 대한 해석**
  - (1) 선행은 문어(요약·서면 보고서)를 생성했다. 우울증 논문은 구어 전사의 비유창성을 문제로 보고 **스스로 제거했다** (원문으로 확인). 우리 연구는 바로 그 비유창성이 신호다.
  - (2) 우울증은 발화 **내용**에, 사고형식장애는 발화 **형식**에 신호가 실린다는 해석은 그럴듯하다. 다만 이번 측정으로 검증된 것은 아니다.
- **실패의 위치**: 이번 결과는 "아무도 안 가본 난이도라서"라고 단정할 근거는 없다. 대신 **"구어 형식을 재현해야 하는 증강은, 선행이 피해 간 바로 그 지점에서 지시 기반 생성이 실패한다"**는 점을 판별·utility 양쪽으로 기록했다는 데 보고 가치가 있다.

## 8. 방법론적 한계 (전체)
- 1·2차는 생성자, 검증 코드, 판정 코드가 같은 세션의 같은 모델에서 나왔다. 2·3차 재시도는 필터 탈락 사유를 보고 다시 쓰거나(2차) 다시 뽑은(3차) 것이라 필터 지표에 대한 최적화가 들어가 있다. 같은 지표로 평가한 Fidelity·Memorization 개선은 그만큼 낙관적으로 읽어야 한다.
- 결번은 무작위가 아니다 (범위를 맞추기 어려운 응답이 빠짐). 그래서 합성 분포의 꼬리가 좁을 수 있다. 3차는 이 때문에 CL/CO 불균형이 생겼다.
- 1·2차의 temperature는 명목 라벨이었다.
- 판별기는 TF-IDF 로지스틱 하나뿐이다. 다른 판별기를 쓰면 수치는 달라질 수 있지만, 이미 AUC가 0.93 이상이어서 결론이 바뀔 가능성은 낮다.
