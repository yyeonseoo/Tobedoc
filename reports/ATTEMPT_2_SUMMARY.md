# 2차 시도 요약 (중간): 파일럿 단계에서 중단 규칙 발동

**상태: 전체 생성 전 중단.** 2차 파일럿의 첫 시도 탈락률이 **58.8%(10/17)**로 선고정 중단 기준(50%)을 넘었다. 사람이 결정할 때까지 전체 생성을 하지 않는다.

## 1. 경과
1. 1차를 문서화하고 커밋했다 (`50b4d24`). 2차 임계값과 판정 코드를 선고정해 커밋했다 (`599a33b`). 선고정 기준으로 1차를 다시 판정하면 Fidelity 불합격 / Diversity 주의 / Memorization **불합격**(3.48×, 사후 기준으로는 주의였음) / Discriminability 불합격이다.
2. Step A: 화자별 비유창성 프로파일을 측정했다 → `reports/04a_speaker_profiles.md`.
3. Step B 첫 생성(이하 "폐기된 v2"): 파일럿 17개를 생성하고 필터·검증 미리보기를 마쳤다 (첫 시도 통과율 70.6%, 파일럿 AUC 0.858). 이어서 전체 생성의 일부를 작성했다.
4. **앵커링 발견 → 전량 폐기.**
   - 폐기된 v2를 작성하는 중에, 생성자(Claude)가 쓴 샘플 상당수가 **새 생성이 아니라 1차 출력을 다시 쓴 것(근접 패러프레이즈)**임을 스스로 발견했다. 파일럿 16개 포함, 일부는 1차 문장 골격을 그대로 유지했다.
   - 원인: 같은 시드 구간(1차와 동일)에, 같은 생성자가 1차 출력을 문맥에 둔 채로 작업했다.
   - 처음에는 파일럿 16개를 보존하고 "다른 주제 각도"로 전체 생성을 다시 하려 했다. 사용자 지시에 따라 이를 철회하고 다음과 같이 처리했다.
     - **파일럿 포함 v2 전량 폐기.** 부분 보존 없이 단일 생성 규칙으로 만든 균질한 세트만 쓴다. 폐기분은 `synthetic/v2_discarded_anchored/`에 보관 (git 제외, 분석에 쓰지 않음).
     - 주제는 실제 면담 프로토콜 범위를 유지하고, "다른 주제 각도" 전략은 쓰지 않는다.
     - 중복 방지 (a): 시드 few-shot 구간을 1차와 다른 윈도우로 바꿨다. 1차 시드에 쓰이지 않은 문장 구간을 우선 쓰고, 부족한 화자만 경계를 옮긴 재분할 구간으로 채운다. 1차와 같은 (시작, 길이)는 금지. 결과: 79% 샘플이 1차 시드와 문장 중복 0, 평균 중복 17.5%. 문장이 적은 6명은 불가피하게 중복된다 (02AR17 100%, 16OV11 91%, 26CT11 90%, 23CT18 86%, 23CT19 68%, 17AR13 48%).
     - 중복 방지 (b): 사후 필터에 "1차 합성 코퍼스(112개)와 6-gram 일치 시 탈락" 검사를 추가했다.
   - 이 절차 변경은 재생성 전에 커밋했다 (`1584d59`). 선고정 임계값과 `validate.py` 평가 로직은 바뀌지 않았다.
5. Step B 재생성 파일럿: 같은 화자 4명(03AR15, 21AP15, 11AR18, 28CT11), 17개를 새 윈도우로 생성 → Step C 필터 → **첫 시도 탈락률 58.8%로 중단.**

## 2. 파일럿 탈락 분석 (첫 시도 17개)

| 탈락 사유 (중복 가능) | 건수 |
|---|---|
| 시드 예시와 6-gram 일치 | 9 (이 사유 하나로만 탈락: 5) |
| filler_per100이 그룹 5백분위 미만 | 4 (모두 28CT11) |
| 1차 코퍼스와 6-gram 일치 | 1 |
| 그 밖의 범위 지표(반복, 문장 길이, 의미 응집) | 0 |

- 그룹별: CO 7건, CL 3건.
- **주원인은 생성자의 시드 구절 재사용이다.** 새 윈도우는 내용이 구체적이다 (예: 일기 5년, 미술치료사 진로, 영상일기). 생성자는 프로토콜 주제를 지키려고 그 내용을 따라가다가 시드의 6단어 구절을 그대로 옮겼다. 1차 출력 앵커링((b) 검사)은 1건뿐이어서, 앵커링 문제는 대부분 해소된 것으로 보인다.
- 28CT11은 화자 프로파일 자체가 저채움말이다 (er 0.4, erm 0.7, 기타 2.6 / 100단어). 그런데 생성자는 그보다 더 적게 썼고, 4개 중 3개가 CO 그룹 5백분위(1.74)에 못 미쳤다. 프로파일을 따르는 지시와 그룹 범위 필터가 충돌하는 화자다.
- **보정 기준선**: 같은 범위 필터를 실제 응답에 적용하면 통과율은 CL 72% / CO 67%다 (복사 필터는 실제 응답에 해당 없음). 범위 필터만 따지면 합성의 탈락은 4/17(24%)로, 실제 응답의 탈락률(28–33%)과 비슷하다. **탈락률 초과는 거의 전적으로 복사 필터 때문이다.**

## 3. 사람이 결정할 사항 (3차 전략 아님, 2차 진행 방식)
1. **그대로 재시도 진행** (사전 규칙상 파일럿 재시도 2회가 남아 있다): 탈락분을 다시 생성하고 전체로 간다. 단, 중단 규칙 판정은 첫 시도 기준이라 이미 발동했으므로, 진행하려면 명시적 승인이 필요하다.
2. **생성 지시 보강 후 파일럿 재실행**: 프롬프트에 "Do not reuse word sequences from the examples" 같은 문구를 넣는다. 사전 원칙(특정 단어 금지 금지)에는 어긋나지 않지만 템플릿 변경이므로 승인이 필요하다.
3. **복사 필터 기준 재검토**: 6-gram 완전 일치는 "you know what I mean like" 같은 구어 상투구에도 걸린다. 다만 이번 탈락 사례(진로 이야기, 일상 행동 묘사 같은 시드 고유 구절. 원문은 04_post_filter.md 참조)는 상투구가 아니라 시드의 특징적 구절이므로, 필터는 의도대로 작동했다고 본다. 기준 완화는 권하지 않는다.
