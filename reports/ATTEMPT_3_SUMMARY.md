# 3차 시도 요약: OpenAI API 실제 샘플링 (최종 시도)

**결론: 불합격 (Discriminability AUC 0.999 > 0.85). 종료 조건에 따라 추가 시도 없이 종료한다. 3차가 최종 시도다.**

> ⚠ `reports/06_validation_v3.md`와 `04_post_filter_v3.md`에는 원본 발췌(또는 원본과 일치한 n-gram)가 들어 있어 공유 금지다 (git 제외). 이 문서에는 원본 발췌가 없다.

## 1. 외부 전송 결정과 근거 (2026-10-02, 사용자 결정: "확인함, 전송 진행")

3차 시도는 프롬프트 안의 시드 few-shot 예시(실제 참여자 전사 발췌, CL 포함)를 OpenAI API로 전송한다. 1–2차에서는 "프로젝트 밖으로 내보내지 않는다"를 원칙으로 삼았으므로, 이 변경의 근거를 기록한다.

**사용자 판단 근거**
1. **라이선스와 공개 범위**: 코퍼스는 UK Data Service ReShare 기록 855021(DOI 10.5255/UKDA-SN-855021)로 공개돼 있다.
   - 라이선스: "Creative Commons: Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)"
   - 파일 접근: "Accessible to: Anyone (open access data)"
   - 다운로드 출처: 원본 7z의 Zone.Identifier `HostUrl=https://reshare.ukdataservice.ac.uk/855021/1/DAIS-C-Annotated-Upload.7z`로 확인.
2. **참여자 동의 범위**: 동의서(SA5_ICForm v.2.2)에 선택 동의 항목이 있다. "(Optional) I consent to the (permanent) archiving of my (anonymised) data, via the UK Data Service, so that it may be used in other studies and/or by other researchers."
3. **전송 대상**: 이미 공개된 익명화 전사 발췌만 보낸다 (전사 단계에서 `<An>` 태그로 익명화됨). 메타데이터·동의서·화자 신원 정보는 보내지 않는다.

**함께 기록하는 반대 방향 문구**: 참여자 설명서(SA5_PIS v.3.2)에는 "Your data will be anonymous to everyone outside of the research team."라는 문구가 있다. 익명성은 위 3번으로 유지된다. 상업 AI 제공자에게 전송하는 것이 동의의 취지에 맞는지는 라이선스로 정해지지 않으며, 사용자가 판단해 진행을 결정했다.

**OpenAI API 데이터 정책 (호출 전 확인, 2026-10-02, developers.openai.com/api/docs/guides/your-data)**
- 학습 사용: "data sent to the OpenAI API is not used to train or improve OpenAI models (unless you explicitly opt in to share data with us)." → 기본적으로 학습에 쓰이지 않는다. 이 프로젝트는 opt-in하지 않는다.
- 남용 모니터링 보관: /v1/chat/completions 기본 30일.
- Zero Data Retention: "subject to prior approval by OpenAI and acceptance of additional requirements" → 호출 설정만으로는 켤 수 없다 (미적용).
- `store` 파라미터: Chat Completions 출력을 distillation/evals 제품용으로 저장할지 정한다. 계정에 따라 기본 저장될 수 있다.
  → **모든 호출에 `store=False`를 명시**한다 (`src/generate_v3.py`, 호출 로그 params에 기록).

**결론**: 학습 미사용은 API 기본 정책으로 보장되고, 출력 저장은 `store=False`로 끈다. 30일 남용 모니터링 보관은 ZDR 승인 없이는 피할 수 없다. 이 잔여 위험은 사용자 판단에 포함된 것으로 기록한다.

## 2. 설정
- 모델: gpt-4o (예상 비용 $0.66, 최악 $1.99 < $5 → 하향 불필요).
  - 단가: input $2.50 / output $10.00 per 1M tokens (2026-10-01 확인).
- temperature 1.0, 호출마다 랜덤 seed, `store=False`. 누적 추정 지출이 $5에 도달하면 즉시 중단.
- 프롬프트: 2차 프롬프트 + 비유창성 위치 지시 한 문단.
- 그대로 재사용: 필터, 치환 감사, 검증, 판정 코드 (수정 없음).
- 바뀐 것은 입출력 경로뿐이다: `validate.py`에 v3 실행 항목을 추가했다. `post_filter`·`generate_v2`는 실행 중에 디렉터리 상수만 v3로 지정한다.

**버그 수정 1건 (래퍼 쪽, 재사용 코드는 수정하지 않음)**: `validate.py`는 import될 때 `sys.argv[1]`을 실행 모드로 읽는다. 그래서 `generate_v3.py filter` 안에서 `post_filter`가 `validate`를 import하면 KeyError('filter')가 났다. `generate_v3._point_filter_to_v3()`에서 `sys.argv`를 인자 없음으로 정리해 해결했다. 실패한 실행은 필터 로그에 아무것도 쓰지 않았다.

## 4. 판정 (선고정 임계값)

| 축 | 1차 | 2차 | 3차 | 3차 판정 |
|---|---|---|---|---|
| Fidelity: 방향 일치 / 가짜 효과 | 5/8, 3개 | 6/8, 0개 | 6/8, 0개 | 합격 |
| Diversity: 최대 \|Δ pairwise cos\| | 0.136 | 0.054 | **0.219** | **불합격** |
| Memorization: overlap / 기준선 | 3.48× | 1.44× | **0.80×** | 합격 |
| **Discriminability: AUC** | 0.940 | 0.932 | **0.999** | **불합격** |
| **first_dist d (합성 CL−CO; 실제 −0.013)** | 0.483 | 0.483 | **0.194** (q 0.46) | — |

**판별 원인은 3차에 추가한 비유창성 지시의 과잉 이행이다.** 10,000단어당 빈도:

| 표현 | 실제 | 3차 | 배율 |
|---|---|---|---|
| um | 0.1 | 64.2 | — |
| uh | 0.1 | 46.3 | — |
| sort of | 45.1 | 140.7 | 3.1× |
| kind of | 52.6 | 129.4 | 2.5× |
| you know | 84.8 | 195.5 | 2.3× |
| I guess | 4.3 | 39.7 | 9.2× |
| kinda | 2.0 | 25.5 | 12.8× |
| it it | 9.4 | 20.8 | 2.2× |
| the the | 11.2 | 34.9 | 3.1× |

- 상위 판별 피처도 `sort of`, `um`, `kind of`, `you know`, `guess`, `uh`, `kinda`다.
- `um`/`uh`는 이 코퍼스의 전사 규약(er/erm)에 없는 미국식 표기다. 프롬프트가 "fillers written as er / erm"을 요구했는데도 모델이 따르지 않았다.
- 문장 의미 유사도도 실제보다 높아졌다 (pairwise cos CL 0.525 vs 0.306). 같은 표현이 반복된 탓으로 보인다.

## 5. 세 시도 종합 결론

**개선된 것**
- **암기·원문 유출**: overlap 3.48× → 1.44× → 0.80×. 최장 공유 구간 15 → 8 → 7단어. 3차는 실제 화자 간 기준선보다도 낮다.
- **효과 보존의 가짜 효과**: 1차의 가짜 효과 3개(MATTR, adj_sim, first_dist)가 2·3차에서는 0개다.
- **합성 CL의 topic drift 과장**: 1·2차에서 d=0.483으로 그대로 남았다. 실제 샘플링(3차)에서 처음으로 0.194로 줄었다. 1·2차의 과장은 프롬프트보다는 **자가 생성자(Claude)의 "조현병 발화" 고정관념**에서 왔을 가능성을 시사한다 (단일 비교라 단정은 못 한다).
- **절차 측면**: 선고정 임계값, 앵커링 폐기, 프롬프트 전수 재검사, 치환 감사, 외부 전송 근거 기록으로 각 결정의 추적성을 확보했다.

**한계로 남은 것**
- **판별 가능성은 세 시도 모두 불합격이다** (0.940 → 0.932 → 0.999). 길이로는 구분되지 않는다 (AUC 0.48–0.57). 매번 **어휘 수준의 문체 습관**이 들통났다.
  - 1차: erm 과용, 정제된 표현
  - 2차: "erm and" 연결, 주제 밀착, 어휘 다양성 과잉
  - 3차: 얼버무림·um/uh 과잉
- 프로파일 수치나 문단 단위 지시로 한 축을 고치면 다른 축이 반대 방향으로 넘친다. 2차의 "다른 말로" 지시는 어휘 다양성 과잉을, 3차의 비유창성 지시는 비유창성 과잉을 낳았다. 지시 기반 조건화로는 실제 분포의 **양(量)**을 맞추기 어렵다.
- 사후 범위 필터는 응답 단위 5–95 백분위 범위만 보므로, 코퍼스 수준의 빈도 과잉(예: 모든 샘플이 상한 근처)은 걸러내지 못한다. 3차 통과분도 판별기에는 거의 완벽히 구분된다.
- 그룹-주제 교란, 소수 화자, 응답 단위의 비독립성은 그대로다.
- **합성 CL은 LLM이 모방한 발화일 뿐 임상적 실체가 아니다.**

**최종 상태**: 선고정 종료 조건에 따라 3차 합성 코퍼스(`synthetic/v3/synthetic_corpus.parquet`, 96개)는 **불합격이며 최종본으로 확정하지 않는다.** 1–3차 산출물은 모두 보존돼 있다 (`synthetic/`, git 제외). 다음 단계는 사람이 결정한다.
