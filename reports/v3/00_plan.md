# v3 분석 계획: 임상 개념 기반 피처와 교란 기준선 (결과 확인 전 고정)

작성 2026-10-23. 그룹 비교 결과를 보기 전에 커밋한다. 변경은 맨 아래 "변경 기록"에 남긴다.

## 배경과 질문

v2와 팀 노트북 점검에서, Reddit 분류 성능은 글 길이·제목 문체·게시판 장르로 상당 부분 설명됐다. 내용어를 그대로 쓰면 주제만으로도 높은 AUC가 나오므로 AUC 자체는 목표가 아니다. v3의 질문은 다음과 같다.

1. 형식적 사고장애(FTD)의 임상 개념에서 출발한 피처가, 길이·주제·장르로 이루어진 교란 기준선 모델보다 성능을 더하는가?
2. 그 피처들의 방향이 DAIS-C 임상 면담에서도 나타나는가?
3. 같은 사람 안에서, 면담자가 되물은 답변(듣는 사람의 혼란)에서 그 피처 값이 달라지는가?

## 데이터와 단위 (v2와 같음)

- 공통 가공: 소문자, 문장부호 제거, NLTK 불용어 제거, 더듬기 제거, 진단 직접 단어 제거 후 내용어만 쓴다.
- Reddit: 글 본문. 주 표본은 조현병 게시판 글 중 가족·보호자로 분류된 글을 제외한 것 + 대조 게시판 글. 독립 단위는 작성자.
- DAIS-C: 면담자 질문 하나에 대한 답변. 독립 단위는 화자.
- 길이: 내용어 40개 이상 단위만 쓰고 앞 40개를 5개씩 8조각으로 나눈다. M4만 v2 E5와 같이 앞 30개를 쓴다.

## 피처 (13개, 고정)

| 임상 개념 | 피처 | 정의 |
|---|---|---|
| 이탈 | `drift_slope` | 첫 조각과의 SBERT 거리를 위치에 회귀한 기울기 (v2) |
| 이탈 | `drift_mean` | 첫 조각과의 평균 거리 (v2) |
| 탈선 | `adj_mean` | 인접 조각 거리 평균 (v2) |
| 이탈 | `late_slope` | 첫 3조각 평균 기준 이후 기울기 (v2) |
| 탈선 | `jump_max` | 인접 조각 거리의 최댓값 (가장 큰 갑작스러운 전환) |
| 탈선 | `adj_sd` | 인접 조각 거리의 표준편차 (전환의 불규칙성) |
| 연합 이완 | `global_coh` | 8조각 모든 쌍의 평균 코사인 유사도 (전역 응집도) |
| 보속 | `sem_redund` | 각 조각(3번째부터)이 바로 앞이 아닌 이전 조각들과 가장 비슷한 정도의 평균 (같은 생각으로 되돌아감) |
| 보속 | `recurrence` | 각 조각의 내용어 중 앞에서 이미 나온 비율 (v2) |
| 사고 빈곤 | `mattr` | 내용어 MATTR, 창 20 (v2) |
| 사고 빈곤 | `sem_density` | 40개 내용어 각각의 SBERT 단어 벡터(정규화)의 평균 벡터 길이. 단어들이 같은 의미 방향을 가리킬수록 큼 (Rezaii et al. 2019의 의미 밀도 개념을 근사) |
| 단어 근사·신조어 | `rare_rate` | wordfreq Zipf 빈도 2.5 미만 단어 비율 (숫자 제외) |
| 음운 연상 | `clang_rate` | 이어지는 두 내용어(각 3글자 이상, 서로 다른 단어)의 끝 3글자가 같은 비율 |

임베딩은 all-MiniLM-L6-v2. 단어 벡터도 같은 모델로 단어 하나씩 임베딩한다.

## 교란 기준선 (Reddit)

- `log_len`: 본문 내용어 수의 로그 (자르기 전 전체 길이)
- `topic`: 본문 내용어 SBERT 임베딩의 KMeans 군집 (k는 5~20 중 실루엣 최대, 그룹 라벨을 보지 않음, v2 E3와 같은 방법), 원-핫
- `title_q`: 제목이 물음표로 끝나는지 (질문형 글 장르)
- `title_len`: 제목 단어 수

## 분석

### M1 (주 분석): Reddit, 교란 기준선 대비 증가분
- 모델 세 가지: 기준선(B), 임상 피처만(C), 기준선 + 임상 피처(B+C). 모두 표준화한 로지스틱 회귀.
- 작성자 단위 StratifiedGroupKFold 5-fold를 5회 반복, 예측을 작성자별로 평균해 작성자 단위 AUC.
- 주 지표: ΔAUC = AUC(B+C) - AUC(B). 같은 작성자 표본을 짝으로 부트스트랩(2,000회)해 95% CI.
- 보조: B+C를 LightGBM(기본값)으로. 참고: 내용어 TF-IDF(단어 그대로) 로지스틱 AUC (주제만으로 얼마나 쉽게 구분되는지 보여 주는 참고값).
- 피처별: 작성자 평균 g, 그리고 기준선 변수로 회귀한 잔차의 g (교란을 뺀 효과). BH-FDR(13개).

판정: ΔAUC의 95% CI 하한이 0보다 크면 "임상 피처가 교란 이상의 정보를 더한다".

### M2 (보조): Reddit 같은 게시판 안, 본인 글 vs 가족·보호자 글
- v2 E1 표본. 1인칭 축약어(im, ive, id, ill)를 지운 뒤 피처를 계산한다(v2 E4에서 확인한 착시 방지). 작성 주체 분류가 규칙 기반이므로 예비 결과다.
- 피처별 작성자 단위 g와 FDR, 임상 피처만의 작성자 단위 AUC.

### M3 (검증): DAIS-C
- 화자 평균 g와 부트스트랩 95% CI(5,000회).
- 방향 일치: M1 잔차 g와 DAIS-C g의 부호 비교 (13개 중 몇 개).
- 모델 이전: Reddit 전체로 학습한 임상 피처만의 로지스틱 모델을 DAIS-C 답변에 적용, 화자 평균 확률로 AUC.
- 혼합효과모형: 피처 ~ 그룹 + 시작 질문 + 성별 + 질문 내용어 수 + (1 | 화자).

### M4 (타당도): DAIS-C 같은 사람 안에서 되물은 답변 vs 나머지
- v2 E5와 같은 되묻기 정의와 앞 30 내용어. 두 종류 답변이 모두 있는 화자만, 화자별 차이의 중앙값과 Wilcoxon 부호순위 검정, BH-FDR(13개).

## 유망 피처 기준 (사전 정의)

다음 세 가지를 모두 만족하면 "유망"으로 표시한다. (1) M1 잔차 g의 95% CI가 0을 포함하지 않음, (2) DAIS-C g가 같은 방향, (3) M4 차이 중앙값이 같은 방향(조현병 쪽으로 큰 값이 되물은 답변에서도 큼).

## 하지 않는 것

- DAIS-C나 M4 결과를 보고 피처 정의나 임계값을 바꾸지 않는다.
- 내용어 TF-IDF 모델의 AUC를 성능 결과로 보고하지 않는다. 참고값일 뿐이다.
