# 00. 분석 계획 (v2, 결과 확인 전 고정)

작성 2026-10-11. 이 문서는 그룹 비교 결과를 보기 전에 커밋한다. 이후 변경은 날짜와 이유를 아래 "변경 기록"에 남긴다.

## 질문

1. (발견) Reddit에서 조현병 게시판 글은 대조 게시판 글보다 의미 이탈 기울기가 큰가?
2. (검증) Reddit에서 정한 지표와 방향이 DAIS-C 임상 면담(조현병 15명, 대조 13명)에서도 나타나는가?
3. (지표 타당도) 연구자가 담화 추적 어려움(DT), 사고 완결 문제(TC)를 표시한 구간에서 자동 지표가 실제로 커지는가?

## 데이터와 단위

| | Reddit | DAIS-C |
|---|---|---|
| 단위 | 글 (본문) | 면담자 질문 하나에 대한 답변 |
| 독립 단위 | 작성자 | 화자 |
| 주 분석 표본 | 조현병 게시판 글 중 가족·보호자로 분류된 글(source = other) 제외 + 대조 게시판 글 | 질문-답변 전체 |
| 기준점 | 제목 | 면담자 질문 (23EB14는 누락) |

- 두 코퍼스 모두 소문자, 문장부호 제거, NLTK 불용어 제거, 더듬기(er/erm 등) 제거, 진단 직접 단어 제거 후 내용어만 쓴다. Reddit 본문이 원래 이 상태라 DAIS-C를 맞춘다.
- 내용어 40개 이상인 단위만 쓰고, 앞 40개를 5개씩 8조각으로 나눠 지표를 계산한다. 길이는 모든 단위에서 같다.

## 지표 (고정)

| 구분 | 지표 |
|---|---|
| 주 지표 | `drift_slope`: 첫 조각과의 SBERT 거리를 조각 위치에 회귀한 기울기 |
| 보조 지표 (5개) | `drift_mean`, `adj_mean`, `late_slope`(첫 3조각 평균 기준), `recurrence`(어휘 재등장률), `mattr` |
| 탐색 지표 | `anchor_first`, `anchor_mean`, `anchor_slope` (기준점과의 거리). 기준점 성격이 코퍼스마다 달라 검증 대상에서 제외 |
| DAIS-C 전용 | `filler_rate` (원문 기준 더듬기 비율) |

임베딩은 all-MiniLM-L6-v2. 기능어·1인칭·접속사 비율은 Reddit 본문에서 불용어가 지워져 계산할 수 없으므로 쓰지 않는다.

## 분석 1: Reddit 발견

- 작성자별로 지표를 평균한 뒤 그룹 비교. Hedges' g와 부트스트랩 95% CI(2,000회), Welch t 검정, 6개 고정 지표에 BH-FDR.
- 분류: 6개 지표로 로지스틱 회귀(표준화). 작성자 단위 StratifiedGroupKFold 5-fold를 5회 반복, 예측을 작성자별로 평균해 작성자 단위 AUC. 부트스트랩 95% CI.
- 순열 검정: 작성자 라벨을 섞어 같은 과정 200회.
- 보조 모델: LightGBM 기본값(튜닝 없음).
- 주제 매칭 민감도: 내용어 TF-IDF를 SVD 40차원으로 줄인 공간에서 1:1 최근접 매칭(비복원), 유사도 하위 25%는 제외. 매칭 표본에서 효과 크기와 AUC를 다시 계산.

판정: 주 지표 g > 0이고 95% CI가 0을 포함하지 않으며 FDR q < 0.05이면 지지. 분류는 AUC 95% CI 하한이 0.5를 넘고 순열 p < 0.05이면 우연 이상.

## 분석 2: DAIS-C 검증 (지표·방향을 Reddit 결과로 고정)

- 화자별로 지표를 평균한 뒤 그룹 비교. Hedges' g와 부트스트랩 95% CI(5,000회).
- 방향 일치: Reddit g와 DAIS-C g의 부호가 같은 지표 수 (6개 중).
- 모델 이전: Reddit 전체로 학습한 로지스틱 모델을 DAIS-C 답변에 그대로 적용하고, 화자별 평균 확률로 AUC와 부트스트랩 CI.
- 혼합효과모형: 지표 ~ 그룹 + 시작 질문 + 성별 + 질문 길이(단어) + (1 | 화자). 그룹 계수와 95% CI. 녹음 방식은 그룹과 완전히 겹쳐 넣을 수 없다.

판정: 주 지표가 Reddit과 같은 방향이고 g의 95% CI가 0을 포함하지 않으면 "재현", 방향만 같으면 "방향 일치", 반대면 "재현 안 됨".

## 분석 3: 태그로 지표 타당도 확인 (같은 사람 안에서 비교)

- DAIS-C 답변 전체의 5내용어 조각 단위로, 연구자 판단 태그 구간이 들어 있는 조각과 없는 조각의 인접 조각 거리(`dist_adj`)를 같은 화자 안에서 비교한다.
- 대상 태그: DT(주), TC(보조). 태그 조각과 비태그 조각이 모두 있는 화자만 쓴다. 화자별 차이(태그 - 비태그)의 중앙값과 Wilcoxon 부호순위 검정.
- 보조: 화자 단위로 DT 밀도(1,000 내용어당)와 주 지표의 Spearman 상관.

## 민감도 분석

- 길이: 앞 내용어 30개, 60개.
- Reddit 표본: 본인이라고 밝힌 글(source = self)만.
- DAIS-C: 더듬기를 남긴 버전은 공통 지표 정의상 하지 않는다 (v1에서 상관 0.95 확인).

## 하지 않는 것

- DAIS-C 결과를 보고 지표·모델·임계값을 바꾸지 않는다. DAIS-C로 학습·튜닝하지 않는다.
- 결과를 본 뒤 지표를 추가해 주 결과로 보고하지 않는다. 추가 분석은 탐색으로 표시한다.

## 한계 (미리 명시)

- Reddit 라벨은 진단이 아니라 게시판이다. 대조 게시판(Jokes, relationships 등)과 장르가 다르다. 작성 주체 분류는 규칙 기반 1차 분류다.
- Reddit은 쓴 글, DAIS-C는 말의 전사다.
- DAIS-C는 26명 규모이고 녹음 방식·성별·시작 질문이 그룹과 겹친다.

## 변경 기록

### 2026-10-11: 탐색 분석 E1, E2 추가 (01_results.md를 본 뒤, E1·E2 결과를 보기 전에 기록)

본 분석에서 Reddit은 게시판 장르, DAIS-C는 면담 주제가 그룹과 겹치는 것이 가장 큰 약점이었다. 이를 직접 겨냥한 두 분석을 탐색으로 추가한다. 결과는 `02_exploratory.md`에 따로 보고하고 본 분석 판정은 바꾸지 않는다.

- E1 (Reddit, 같은 게시판 안): r/schizophrenia 안에서 본인 글(source = self)과 가족·보호자 글(source = other)을 비교한다. 두 범주에 모두 글이 있는 작성자는 제외한다. 앞 40 내용어, 6개 고정 지표, 작성자 단위 Hedges' g와 부트스트랩 95% CI, BH-FDR. 6개 지표 로지스틱 회귀의 작성자 단위 그룹 5-fold AUC(5회 반복). 작성 주체 분류는 규칙 기반이므로 팀 수작업 확인 전까지 예비 결과로 표시한다.
- E2 (DAIS-C, 주제 맞춤): 앞 40 내용어 이상 답변의 내용어 전체를 SBERT로 임베딩해 KMeans로 주제 군집을 만든다. 군집 수는 4~8 중 실루엣 점수가 가장 높은 값으로 정한다(그룹 라벨을 보지 않음). 두 그룹 화자가 각각 2명 이상인 군집의 답변만 남겨, 6개 지표마다 혼합효과모형 지표 ~ 그룹 + 군집 + 성별 + 시작 질문 + (1 | 화자)를 적합한다. 그룹 계수와 95% CI를 보고한다.

### 2026-10-11: 탐색 분석 E3 추가 (E1·E2 결과를 본 뒤, E3 결과를 보기 전에 기록)

E2는 DAIS-C 답변이 적고 주제가 그룹과 거의 겹쳐(실루엣 약 0.1, 4개 군집 중 2개는 한 그룹뿐) 주제 맞춤이 제한적이었다. 표본이 큰 Reddit에서 주제 보정을 다시 한다.

- E3 (Reddit, 주제 군집 보정): 주 분석 표본(가족·보호자 글 제외, 앞 40 내용어 이상)의 글 내용어 전체를 SBERT로 임베딩해 KMeans 군집을 만든다. 군집 수는 5~20 중 실루엣 점수가 가장 높은 값(그룹 라벨을 보지 않음). 두 그룹 글이 각각 30개 이상인 군집만 남긴다. 6개 지표를 표준화한 뒤 글 단위 회귀 지표 ~ 그룹 + 군집을 적합하고 표준오차는 작성자 단위 군집 강건 추정을 쓴다. 군집별 그룹 차이(g)도 함께 보고한다.
