# DAIS-C 합성 발화 증강: 최종 리포트

**요약: 합성 데이터 112개(CL 56 / CO 56)를 생성하고 4축으로 검증했다. 원문 암기와 mode collapse는 심각하지 않다. 그러나 실제와 쉽게 구분되고(AUC 0.94), CL과 CO의 차이 구조를 절반만 보존하며, CL에서는 "주제 이탈" 효과를 실제에 없는데도 만들어냈다. 현 상태로는 하류 분석용 증강 데이터로 쓰기에 부적합하다.**

## 2. 4축 검증 요약과 판정

> 판정 기준은 이 리포트를 쓰면서 정했다. 사전 등록이 아니므로 기준 자체도 검토 대상이다.

| 축 | 핵심 결과 | 기준 | 판정 |
|---|---|---|---|
| **Fidelity** | KS q<.05인 피처: CL 4/11, CO 6/11. MATTR가 두 그룹 모두 실제보다 높음(CO W/SD=1.35). 효과 보존: 실제에서 유의한 8개 중 **4개만 보존**, n_sentences는 뒤집힘(유의). 실제에 없는 CL−CO 차이가 합성에서 3개 생김(MATTR, adj_sim, first_dist) | 합격: 보존 ≥75%이고 유의한 뒤집힘·가짜 효과 없음 / 주의: 보존 50–75% / 불합격: 유의한 뒤집힘이나 가짜 효과가 있음 | **불합격** |
| **Diversity** | 준중복 0쌍, 완전 중복 0. distinct-1/2가 모두 실제 95% 구간 안. 시드 화자 수렴 gap 0.123으로 실제 LOO 0.132 이하. 다만 샘플 간 평균 cos가 CL 0.39 vs 0.31, CO 0.55 vs 0.41로 높음 | 합격: 앞의 넷을 충족하고 pairwise cos 차이 < 0.05 / 주의: 차이 0.05–0.15 / 불합격: 준중복 다수 또는 distinct-n이 구간 밖 | **주의** (의미 수준 동질화) |
| **Memorization** | 5-gram overlap 2.7% (실제 화자 간 기준선 0.8%의 3.5배, 시드 화자 대상 1.8%). 최장 공유 15단어로 기준선 최대 16 이하. 합성→실제 최근접 거리가 실제→실제보다 가까움(p=7e-8). 단, 실제 p5보다 가까운 합성 샘플은 6.2%(기대치 5%). 육안 확인에서 **시드의 특징적 절을 그대로 옮긴 샘플** 확인 (예: syn_18UG11_01 — 시드와 11단어 연속 일치, syn_18UG14_02. 원문 대조는 03_validation.md §3c) | 합격: overlap ≤ 기준선 2배이고 특징적 복사 없음 / 주의: 2–5배이거나 특징적 복사가 일부 있음 / 불합격: 기준선 최대를 넘는 복사 구간이 있거나 p5 미만 비율 > 10% | **주의** |

### 축별 근거
- **판별 아티팩트 (3d).**
  - 합성 쪽 상위 피처: `erm and`, `erm`, `bit`, `quite`, `actually`, `really`, `erm so`.
  - 실제 쪽 상위 피처: `er`, `ah`, `erm er`, `that that`, `it it`, `th`.
  - 해석: 생성자가 채움말을 `erm`으로 획일화했고 `er`, 단어 반복, 절단어는 덜 만들었다. "quite a bit / actually"류의 정돈된 영국식 구어 상투어도 과다하다.
  - MATTR이 높은 것(어휘 반복 부족)과 같은 원인이다. 파일럿에서 이미 진단했고 full 라운드에서 교정을 시도했지만 효과는 작았다 (MATTR 편차 0.070 → 0.057).
- **CL 캐리커처 (3a).**
  - 실제 데이터에서 CL과 CO의 의미 응집도 차이는 0에 가깝다 (adj_sim d=+0.02, first_dist d=−0.01).
  - 합성에서는 CL이 덜 응집적이고 첫 문장에서 더 멀리 이탈한다 (d=−0.34, +0.48, 둘 다 q<.05). 화자 단위로 봐도 같다.
  - 즉 LLM이 조현병 발화에 대한 **고정관념(탈선)을 실제보다 과장해 주입했다.** 이 데이터로 "응집도 지표가 CL을 탐지한다"는 결론을 내면 아티팩트를 검증하는 셈이 된다.
- **사라진 효과 (3a).**
  - 실제 CL은 CO보다 명사·동사 비율이 높고(d=+0.48, +0.52) 부사 비율이 낮다.
  - 합성에서 명사 차이는 뒤집혔고 동사 차이는 사라졌다.
  - 부사·대명사·채움말·토큰 수 효과는 방향이 보존됐다 (대명사는 과장되어 d 비율 2.6).
- **동질화 (3b).** 샘플 수준의 중복은 없다. 그러나 CO 합성 샘플들이 서로 비슷하다 (평균 cos 0.55). 대부분 같은 실험 과제를 이야기하고, 생성자 한 명의 서술 습관이 겹친 결과로 보인다.

## 3. 한계
1. **합성 CL은 "LLM이 모방한 발화"이며 임상적 실체가 아니다.** 진단 근거나 증상 지표의 대리 변수로 쓸 수 없다. 위 캐리커처 결과가 그 위험을 직접 보여준다.
2. **생성자와 평가자가 독립적이지 않다.** 같은 세션의 같은 모델이 생성 코드, 응답 작성, 검증 코드를 모두 맡았고, 파일럿 검증 결과를 본 뒤 full 라운드를 생성했다. 판정 기준도 사후에 정했다.
3. **직접 생성 모드.** 확률적 샘플링이 없고 temperature는 명목상이다. 그래서 temperature 조건 비교가 불가능하고, 샘플 다양성이 생성자 한 명의 습관에 묶인다. 거부율 0%도 API 생성의 거부율과 같은 의미가 아니다.
4. **화자 수 제약.**
   - 시드 화자는 27명이고 실제 응답의 상당 부분이 소수 화자에 쏠려 있다 (03EB14·21AN11).
   - 02AR17과 16OV11은 시드 구간이 3–4개뿐이라 구간이 재사용됐다.
   - 응답 단위 검정은 화자 내 비독립성을 무시한다. 화자 단위 d를 함께 보고했다.
5. **주제 교락.** CO 10명은 "실험이 어땠나", CL 대부분은 창의성 질문으로 시작했다. 실제 CL−CO 차이에는 주제 효과가 섞여 있고, 합성도 그것을 물려받는다.
6. **측정 한계.**
   - 원전사에 구두점이 없어 "문장"은 spaCy 파서가 추정한 분절이다.
   - filler 목록에 `like`, `kind of` 같은 다의어가 포함돼 있다.
   - 상한 350토큰 때문에 긴 응답 꼬리(실제의 4.4%)는 재현되지 않았다.
7. **라이선스·재배포.**
   - 코퍼스 라이선스를 확인하지 못했으므로 합성 데이터는 `./synthetic/` 밖으로 내보내지 않는다.
   - `reports/03_validation.md`와 `02_pilot_preview.md`에는 원문 발췌(육안 확인용)가 들어 있어 **리포트도 재배포 금지**다.
   - 모든 산출물은 실제/합성 분리 상태를 유지했다 (합성은 `synthetic=True`이고 별도 파일).

## 4. 다음 단계 제안
1. **판별 아티팩트 제거 (Discriminability·Fidelity 불합격 대응).**
   - 시드 화자별 실측 프로파일을 프롬프트에 명시 목표로 넣는 템플릿 v2를 만든다: er/erm 비율, 반복·절단어 빈도, MATTR.
   - 가능하면 API 생성으로 바꿔 실제 temperature 조건을 돌린다.
   - 생성 뒤에는 3d 분류기 점수로 rejection sampling을 하고, 반드시 **분류기를 학습하지 않은 홀드아웃 시드 화자**에서 AUC를 다시 잰다 (과적합 방지).
2. **CL 캐리커처 차단.**
   - 응집도(adj_sim, first_dist)를 시드 화자의 실측값에 맞추도록 조건을 건다.
   - 효과 보존 표에서 "실제에서 비유의인데 합성에서 유의한 피처"를 자동 실패 조건으로 추가한다.
   - 연구자 블라인드 평가(실제/합성 구분, 그룹 추정)도 덧붙인다.
3. **암기 필터.**
   - 시드 화자와 공유하는 8단어 이상 구간 중 상투구가 아닌 것이 있는 샘플은 재생성 대상으로 지정한다. 상투구 = 원본에서 3명 이상 화자가 쓰는 n-gram 화이트리스트.
   - 이 필터를 `ingest`의 치환 감사처럼 자동 검증 단계로 넣는다.

## 5. 재현
```
python src/explore.py                 # Step 0 통계
python src/preprocess.py              # -> data/processed/corpus.parquet, reports/01
python src/generate.py prepare        # -> synthetic/prompts.jsonl
#   (synthetic/manual_responses/*.txt 작성: 직접 생성)
python src/generate.py ingest         # -> synthetic/synthetic_corpus.parquet, generation_log.jsonl, substitution_audit.csv
python src/validate.py pilot          # -> reports/02_pilot_preview.md
python src/validate.py                # -> reports/03_validation.md, figures/, validation_metrics.json
```
모든 설정은 `config.yaml`에 있고 seed는 42다. 직접 생성 단계는 결정적이지 않으므로, 재현성은 저장된 응답 파일과 로그로 보장한다.
