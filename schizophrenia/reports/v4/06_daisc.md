# v4e: 생성 발화에서 찾은 지표를 실제 조현병 면담(DAIS-C)에 적용

재현: `python src/v4e_daisc.py`. 결과를 본 뒤 정한 탐색이다.

DAIS-C 가공본은 내용어만 남아 있어 지표를 내용어 기준으로 다시 정의했다(내용어 5개 창과 질문의 유사도 평균 q_mean, 마지막 10 내용어와 질문의 유사도 q_end, 앞 15 내용어의 의미 밀도 sem_density, combo = z(q_mean) + z(q_end)). 축약형 잔여물(im, dont, thats 등)과 말버릇(like, yeah, know, mean 등)은 불용어 목록을 빠져나가 내용어로 남으므로, 생성 발화와 DAIS-C 모두에서 뺐다(DAIS-C에서 특히 많다). 정리 후 내용어 15개 이상이고 질문 내용어가 2개 이상인 답변 366개(26명)를 썼다.

생성 발화의 질문은 내용어 2~3개짜리 한 문장이지만, DAIS-C의 '질문'은 직전 면담자 발화 전체라 더 길고(내용어 중앙값 5개) 맞장구나 끊긴 말이 섞여 있다. 그래서 질문 내용어가 5개 이하인 답변만으로도 같은 비교를 했다(2절 아래).

## 2. 같은 사람 안: DT 표시 답변 대 일반 답변

DT는 DAIS-C 연구진이 자신들의 사고장애 분석 틀에서 담화 추적(discourse tracking) 특징으로 표시한 부분이다(코퍼스 Readme). 임상적인 사고장애 판정이 아니고, 표시 절차와 평가자 일치도는 공개되지 않았다. 참여 환자는 항정신병약을 꾸준히 복용 중이고 연구 참여 동의 능력이 있다고 판단된 사람으로 제한되어, 급성기 환자는 포함되기 어렵다.

## 3. 같은 사람 안: 면담자가 되물은 답변 대 아닌 답변

"what do you mean", "did you say", "pardon"처럼 실제로 다시 묻는 경우만 셌다. "I know what you mean" 같은 맞장구와 "sorry to hear" 같은 말은 뺐다. 되물음 답변은 4개, 두 종류 답변을 모두 가진 화자는 3명이라 검정할 수 없다.

## 5. 해석

- **생성 발화에서 찾은 질문 기준 지표는 실제 환자 면담에서 작동하지 않았다.** 같은 사람 안에서 DT 표시 답변과 일반 답변을 비교하면 예상 방향인 화자가 절반 정도였다(q_mean 7/13). 집단 기준도 차이가 없었다. 질문이 짧은 답변만 보면 4/5명이 예상 방향이었지만 표시 답변이 6개뿐이라 판단할 수 없다. 질문 정의 차이가 결과를 가렸을 가능성은 남는다.
- **의미 밀도는 차이가 없었다**(5/13). 말버릇 단어를 빼기 전에는 표시 답변의 의미 밀도가 더 높게 나왔는데(13명 중 11명), like, yeah 같은 단어가 반복되어 생긴 차이였다.
- 가능한 이유:
  1. **실제 사고장애는 교과서적 사고장애보다 훨씬 약하고 부분적이다.** 생성 발화의 2~3단계는 답변 대부분이 질문에서 벗어나지만, DAIS-C의 표시 답변은 대부분 질문과 관련된 말 속에 일부 구간만 이상하다.
  2. **DT는 사고장애 판정이 아니다.** 연구진이 담화 추적 특징으로 표시한 부분이라, 지표가 잡으려는 사고장애와 같은 대상이라는 보장이 없다. 표시 절차와 일치도도 공개되지 않았다.
  3. **수가 적다.** 표시 답변 28개, 비교 가능한 화자 13명이다.
- 정리: 생성 발화에서 작동한 지표가 실제 환자 발화로 그대로 옮겨진다는 근거는 없다.
