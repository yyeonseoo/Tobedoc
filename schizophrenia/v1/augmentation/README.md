# 보관: LLM 합성 데이터 증강 (1–3차, 종료)

결론과 전체 경과는 [REPORT.md](REPORT.md) 하나에 있다. 세 시도 모두 판별 가능성 기준(AUC ≤ 0.85)에 불합격해서 합성 코퍼스는 쓰지 않는다. 본 연구는 증강 없이 질문-답변 단위 분할로 진행한다 (`src/build_qa_units.py`, `reports/02_qa_units.md`).

| 경로 | 내용 | git |
|---|---|---|
| `REPORT.md` | 통합 최종 보고서 (1–3차, 선행 기준 재채점 포함) | 추적 |
| `src/` | 생성(`generate*.py`), 필터, 검증(`validate.py`), 판정, 진단, 재채점 코드 | 추적 |
| `reports/` | 단계별 상세 리포트, 그림, `*validation_metrics.json` | 추적 (원문 발췌가 든 리포트는 제외) |
| `config.yaml` | 보관 시점의 전체 설정 (생성·검증·선고정 임계값·OpenAI 설정) | 추적 |
| `synthetic/` | 합성 코퍼스·프롬프트·로그·감사표 (1차, v2, v3, 폐기본) | **제외** (원본 시드 발췌 포함) |
| `data/` | 화자·응답 비유창성 프로파일, 필터용 실제 지표 | **제외** (원본 유래) |

재실행: 이 폴더의 코드는 경로가 프로젝트 루트 기준이라 여기서 바로 돌지 않는다. 필요하면 보관 직전 커밋을 체크아웃해서 실행한다 (`git log -- archive/augmentation`으로 확인). 3차(`generate_v3.py`)는 루트 `.env`의 `OPENAI_API_KEY`가 필요하다.
