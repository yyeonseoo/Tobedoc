# PSYCHE + TLC 지시: 큰 모델에서 말 장애가 나오는가

## 계획 (2026-11-16, 생성 전 작성)

**배경.** 팀 노트북(V2)은 PatientHub의 PSYCHE를 Qwen 2.5 1.5B로 돌려 조현병 가상 환자를 만들었다. 원본은 증상 내용(환청, 편집 사고)은 나왔지만 말의 와해는 없었다. "말수 줄이기"와 "와해" 지시를 더해도 답이 오히려 길어졌고 와해가 보이지 않았다(조건마다 1회).

**질문.** 같은 PSYCHE 구조에서 모델을 GPT-4.1로 바꾸고, 약한 지시 대신 v1에서 작동한 TLC 정의와 단계 문구를 넣으면 의도한 말 장애가 나오는가.

**설계**
- PSYCHE 원본 프롬프트(`psyche/`, PatientHub 커밋 54d5c87)를 그대로 쓴다. MFC 생성 3단계(Profile → History → Behavior)와 환자 지시문 모두 원본과 같다. MFC는 원본처럼 스키마를 강제하는 구조화 출력으로 받는다. 온도는 PatientHub 기본값 0.7.
- 환자 3명: 조현병 25세 남성(팀 노트북과 같은 입력), 34세 여성, 48세 남성. MFC는 환자마다 한 번 만들고 모든 조건에서 같이 쓴다.
- 조건 4개: BASE(PSYCHE 원본), DER(탈선 2단계), INC(지리멸렬 2단계), POV(말의 빈곤 2단계). TLC 조건은 원본 환자 지시문 끝에 말하기 방식 절을 붙인다. 정의와 단계 문구는 v1과 같고(`src/tlc.py`), MFC의 사고 과정이나 말의 양과 다르면 이 절을 따르라고 적는다.
- 질문 8개: 팀 노트북의 5개(내원 이유, 최근 기분, 수면, 이상한 경험, 생활 영향)에 열린 질문 3개(가족, 하루 일과, 앞으로 몇 주 계획)를 더한다. 탈선은 긴 답에서 드러나기 때문이다.
- 환자 3명 × 조건 4개 × 반복 1 = 면담 12개, 96턴.
- 채점: GPT-4.1이 썼으므로 Claude 에이전트가 조건을 모르는 채 턴 단위로 채점한다(v1 채점표). 지표는 `src/metrics.py`, 같은 환자의 BASE 턴 기준 z.
- 비용 상한 2.5달러(예상 약 1.5달러).

**판정 (조건마다, 턴 단위 24턴 대 BASE 24턴)**
1. 발현: 의도한 항목 평균 점수 ≥ 1.0이고 BASE보다 높다(Mann-Whitney 단측 p < .05).
2. 지표: 담당 지표 z가 BASE보다 높다(단측 p < .05).
3. 지속: 의도한 항목이 1점 이상인 턴 ≥ 75%.

세 가지를 모두 만족하면 "작동". 함께 보고: BASE에서 어느 항목이든 1점 이상인 턴 비율, 답변 길이, 환자가 진단명이나 "psychosis"를 직접 말한 턴 수, MFC의 말의 양과 사고 과정 값.

**하지 않는 것.** 결과를 보고 지시를 고쳐 다시 만든 것은 이 판정에 쓰지 않는다. 팀 노트북 결과(Qwen 1.5B)와는 MFC가 달라 숫자로 비교하지 않고 원문만 비교한다.

### 5. 해석

- **사전 기준대로면 통과한 조건은 없었다.** 처음 계산에서 지리멸렬은 채점은 통과했지만(1.00점, 지속 79%) 놀람도가 오르지 않았다(z 0.18, p = .15). 결과를 본 뒤 놀람도를 머뭇거림을 뺀 텍스트로 계산하도록 지표를 고쳤고(아래), 고친 지표로는 지리멸렬도 통과한다(z 2.35, p < .001). 이 통과는 사후 수정에 따른 것이다. 말의 빈곤은 거의 통과했다(평균 0.96점, 지표 p < .001, 지속 92%, 답변 중앙값 15단어). 탈선은 약했다(0.50점, 지속 50%).
- **MFC의 사고 과정 값은 말투로 옮겨지지 않았다.** GPT-4.1이 만든 MFC 셋 모두 사고 과정에 주제 이탈이나 탈선을 적었지만, BASE 면담은 어느 항목도 거의 채점되지 않았다(1점 이상 턴 8%). 팀 노트북(Qwen 1.5B)에서 와해가 안 보인 것은 모델 크기만의 문제가 아니다. PSYCHE 환자 지시문은 사고 과정을 "일관되게 유지하라"고만 하고 어떻게 말하는지는 정하지 않는다.
- **PSYCHE 지시문이 TLC 지시를 약하게 만든다.** 같은 GPT-4.1과 같은 TLC 문구로 v1(짧은 인물 지시문)에서는 탈선 1.44점, 지리멸렬 1.96점이 나왔다. PSYCHE 지시문의 "묻는 것만 답하라", MFC의 말의 양 "감소", 머뭇거림 넣기 규칙이 함께 들어가면서 탈선은 사고의 흐름이 끊기기보다 증상 설명이 길어지는 쪽으로 나왔다(중앙값 126단어, 우회증 0.25점). 탈선 조건에서 환자가 "말이 뒤섞인다"고 자기 말투를 설명하는 경우도 있었다.
- **지리멸렬은 단어 결합이 아니라 내용의 기괴함으로 나왔다.** "문이 숨 쉰다", "TV가 윙크한다"처럼 문장은 대체로 문법에 맞고, 단어의 25%가 "uh, um" 같은 머뭇거림이었다. 머뭇거림은 예측하기 쉬워 놀람도를 끌어내렸다. 그래서 `src/metrics.py`의 놀람도를 머뭇거림을 뺀 텍스트로 계산하도록 바꿨다. 지표 세트 검증 자료에는 머뭇거림이 거의 없어(0~0.5%) 지리멸렬 단계와의 ρ가 그대로였다(GPT-4.1 두 세트 0.851 -> 0.856, 0.851 -> 0.845, Claude 세트는 머뭇거림 0개라 같음). v1 결과도 판정은 같고 놀람도 z만 소수점 둘째 자리에서 바뀌었다.
- **진단명을 직접 말한 턴은 0개였다.** 팀 노트북 Qwen 1.5B에서는 "my schizophrenia" 같은 표현이 나왔다. 큰 모델은 PSYCHE의 "진단명을 말하지 마라" 규칙을 지켰다.
