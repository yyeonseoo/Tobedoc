# 페르소나 모델 v1 계획 (2026-11-08, 생성 전 작성)

v4, v4b, v4j는 이전 단계 실험 이름이다(pre-persona 브랜치 `before_persona/reports/v4/`).

## 목적

인물 설정과 TLC 증상 설정을 넣으면 여러 턴 면담이 나오는 프롬프트 기반 페르소나 모델(src/persona_model.py)을 만들고, 설정한 증상이 면담 내내 의도대로 나오는지 고정 지표 세트(src/metrics.py)와 교차 블라인드 평가로 확인한다.

## 설계

- **인물 3명**: A 34세 남성, 혼자 삶, 물류창고 시간제 근무, 축구와 요리(v4와 같음) / B 52세 여성, 병동 간호사로 25년 일하고 은퇴, 사별, 정원 가꾸기(v4b와 같음) / C 27세 여성, 콜센터에서 일하다 그만둠, 어머니와 삶, 그림 그리기(새 인물).
- **증상 설정 5개**: 측정 가능한 항목(v4j에서 통과한 지표가 있는 항목)만 쓴다. 내용 빈곤은 지표가 실패해 넣지 않는다.

| 설정 | 내용 | 확인할 지표 |
| --- | --- | --- |
| NORM | 사고장애 없음 (대조) | 기준값 |
| DER | 탈선 2단계 | elv_mean (질문 유사도, 낮음) |
| INC | 지리멸렬 2단계 | surp_mean (놀람도, 높음) |
| POV | 말의 빈곤 2단계 | n_words (단어 수, 낮음) |
| MIX | 탈선 1 + 보속 1 + 말의 빈곤 1 | elv_mean, mattr, n_words |

- **면담**: 고정 질문 8개를 순서대로 묻고, 앞 대화를 모두 기억한 채 답한다. Q01~Q06은 v4와 같고, Q07 How have you been sleeping lately?, Q08 What are your plans for the next few weeks?를 더한다.
- **지시문**: 인물 설명 + 증상 항목의 TLC 정의와 단계 기준(v4b, v4j와 같은 문구) + "면담 내내 같은 사람으로, 증상도 내내 유지" + 구어체 영어, 진단 용어 금지. **지표는 지시문에 넣지 않는다.** 단어 수도 지시하지 않는다(말의 빈곤 외에는 "자연스러운 길이").
- **생성 모델 2개**: GPT-4.1(API, temperature 0.9, 실제로 한 턴씩 대화) / Claude(에이전트가 같은 지시문으로 면담 전체를 한 번에 작성). Claude는 진짜 여러 턴 호출이 아니라는 차이가 있다.
- **규모**: 인물 3 × 설정 5 × 반복 2 = 면담 30개 × 8턴 = 생성 모델마다 240턴.
- **비용 상한**: GPT 생성과 평가를 합쳐 2.5달러를 넘으면 코드가 멈춘다(토큰 수로 계산, GPT-4.1 입력 2달러, 출력 8달러 / 100만 토큰).

## 평가

- **교차 블라인드 평가(턴 단위)**: 모든 턴을 섞고 인물, 설정, 턴 순서를 가린 채, 쓴 모델과 다른 모델이 평가한다(Claude가 쓴 것은 GPT-4.1, GPT-4.1이 쓴 것은 Claude 에이전트). 평가표는 v4 TLC 평가표(6항목 + 전체 와해)에 말의 빈곤을 더한 것.
- **지표**: metrics.py로 턴마다 계산하고, 같은 생성 모델의 NORM 턴 기준으로 표준화(flags)한다.

## 판정 (계산 전 고정, 생성 모델마다)

단일 증상 설정(DER, INC, POV) 각각:
1. **발현**: 면담 단위 평균(면담 6개)에서 의도한 항목의 평가 점수가 NORM 면담 6개보다 높다(Mann-Whitney 단측 p < .05). 그리고 평균 1.0점 이상.
2. **지표**: 면담 단위 평균 표시(z)가 NORM보다 높다(Mann-Whitney 단측 p < .05).
3. **지속**: 의도한 항목이 1점 이상인 턴의 비율이 평균 75% 이상(8턴 중 6턴).

세 가지를 모두 만족하면 그 설정은 "작동". 함께 보고: 다른 항목 점수(특이성), NORM의 오탐(어느 항목이든 평균 1점 이상인 턴 비율), MIX의 세 항목 평균 점수와 지표.

## 하지 않는 것

- 지표나 평가 결과를 보고 지시문을 고쳐 다시 생성한 결과를 같은 판정에 쓰지 않는다. 고친다면 v1.1로 따로 기록한다.
- 인물의 사실 일관성(이름, 직업이 턴마다 바뀌지 않는지)은 이번에 자동 판정하지 않는다.
