# v4 계획: 단계별 사고장애 발화로 지표 점검 (2026-10-28, 결과 보기 전 작성)

## 목적

실제 진단 데이터가 없는 상황에서, 지표가 **사고장애의 정도를 따라가는지**와 **사고장애가 아닌 요인에 흔들리지 않는지**를 통제된 발화로 확인한다. 생성 발화는 실제 환자가 아니므로, 이 결과로 "환자의 말이 더 이탈한다"는 결론은 내지 않는다.

## 생성 발화 (작성: Claude)

- 가상 인물 1명(34세 남성, 혼자 삶, 물류창고 시간제 근무, 축구와 요리를 좋아함)을 모든 발화에 고정한다.
- 면담 질문 10개를 고정한다.
- 조건 20개: 질문마다 1개씩, 총 200개. 발화마다 150~170단어의 구어체 답변.

| 종류 | 조건 | 기준 |
|---|---|---|
| 정상 | N0 | 질문에 맞게 답함 |
| 대조 | NMULTI | 질문과 관련된 여러 하위 주제를 차례로 말함 (정상적인 화제 전환) |
| 대조 | CIRC1, CIRC2 | 우회증: 불필요한 세부로 돌아가지만 결국 질문에 답함 |
| 측정 대상 | DER1~3 | 탈선: 생각이 관련 없는 쪽으로 미끄러짐 |
| | TAN1~3 | 주제 이탈: 질문에 엉뚱하거나 비껴간 답 |
| | INC1~3 | 지리멸렬: 문장 안 연결이 깨짐 |
| | PER1~3 | 보속: 같은 말·생각으로 되돌아감 |
| | CLANG1~3 | 음향 연상: 소리로 단어가 이어짐 |

단계 기준은 TLC(Andreasen 1979, 1986)의 정의와 심각도 기준을 요약해 쓴다. 1 = 가끔, 대부분 이해 가능. 2 = 자주, 이해에 지장. 3 = 대부분, 이해 어려움.

## 생성기 검증 (GPT 블라인드 평가)

- 200개를 섞고 조건 표시를 가린 채 GPT(사용 가능한 최상위 모델, temperature 0)에게 TLC 항목별 0~3점과 전체 와해 정도 0~3점을 매기게 한다.
- 통과 기준: ① 측정 대상 조건에서 해당 항목 점수의 평균이 1 < 2 < 3 단계 순서 ② 의도한 단계와 전체 와해 점수의 Spearman ρ ≥ 0.6 ③ N0·NMULTI·CIRC의 전체 와해 평균 ≤ 1.
- 통과하지 못한 조건은 지표 판정에서 빼고 그 사실을 보고한다.

## 지표

모든 발화를 정확히 같은 길이로 자른다.
- **TF-IDF (팀장님 노트북 피처)**: 원문 앞 100토큰. adj_semantic_distance, semantic_drift_slope, max_semantic_drift.
- **SBERT (v3)**: 불용어 제거 후 앞 40 내용어, 5개씩 8조각. drift_slope, drift_mean, adj_mean, late_slope, jump_max, adj_sd, global_coh, sem_redund, recurrence, mattr, sem_density, rare_rate, clang_rate.
- **질문 기준 거리 (v2)**: 질문과 각 조각의 SBERT 거리. anchor_first, anchor_mean, anchor_slope.

## 지표 판정

예상 방향: 이탈 지표(drift, adj, jump, anchor, TF-IDF 3개)는 +, global_coh는 −, 보속 조건에서 recurrence·sem_redund는 +, 음향 연상 조건에서 clang_rate는 +.

1. **민감도**: 탈선·주제 이탈·지리멸렬 조건(N0를 0단계로 포함)에서 단계와 지표의 Spearman ρ. |ρ| ≥ 0.4이고 예상 방향이면 통과.
2. **특이도**: NMULTI, CIRC1, CIRC2의 지표 평균이 DER2·TAN2 평균보다 예상 방향으로 낮아야 통과.
3. 보속·음향 연상은 해당 전용 지표(recurrence, sem_redund, clang_rate)만 같은 방식으로 본다.

## DAIS-C 확인 (예비)

민감도와 특이도를 모두 통과한 지표만 쓴다. 같은 사람 안에서 연구자 판단 표시(DT)가 있는 답변과 없는 답변의 평균을 비교한다. 지표 계산 규칙은 위와 같다(앞 40 내용어 이상인 답변만). 판정: DT 답변 쪽이 예상 방향인 화자의 비율과 부호 검정. 화자 수가 적어 예비 결과로만 보고한다.

## v4f 계획: 미묘한 국소 사고장애와 구간 지표 (2026-10-28, 생성 전 작성)

06에서 실제 사고장애가 생성 발화보다 훨씬 약하고 일부 구간에만 나타난다는 점이 드러났다. 이에 맞춰 생성과 지표를 바꾼다.

- **생성**: GPT-4.1, v4b와 같은 인물·질문 8개. 조건 7개: N0(정상), CIRC(우회증 1단계, 대조), 국소 사고장애 5종(DER, TAN, INC, PER, CLANG). 국소 조건은 "답변 대부분은 정상, 한두 문장(약 15~30단어)만 해당 사고장애, 약하게"로 쓰고 그 구간을 [[ ]]로 표시하게 한다. 질문당 2회, 총 112개. 표시는 지표 계산 전에 지운다.
- **지표** (내용어 기준, DAIS-C와 같은 정의, 5 내용어 창):
  - q_min: 질문과 가장 유사도가 낮은 창의 유사도
  - q_dip: q_mean − q_min (답변 평균 대비 가장 깊이 떨어진 정도)
  - jump_max: 겹치지 않는 5 내용어 조각 사이 최대 거리
  - 비교용 q_mean (06의 답변 평균 지표)
- **판정** (생성 발화):
  1. 답변 수준: 같은 질문·같은 회차의 N0 대비 국소 조건의 차이가 예상 방향(q_min ↓, q_dip ↑, jump_max ↑)인 쌍의 비율, 부호 검정. 사고장애 5종 합쳐서, 그리고 종류별로.
  2. 위치: 국소 조건에서 q_min 창(또는 jump_max 조각)이 [[ ]] 구간과 겹치는 비율을, 같은 답변에서 무작위 창이 겹칠 확률(우연 수준)과 비교.
  3. 대조: CIRC가 N0보다 q_dip이 크게 나오면(우회증을 사고장애로 오인) 문제로 보고한다.
- **DAIS-C**: 생성 발화에서 1 또는 2를 통과한 지표만. ① 같은 사람 안 DT 답변 대 일반 답변 ② DT 답변 안에서 q_min 창이 DT 표시 단어와 겹치는 비율 대 우연 수준.

- 2026-10-28 (v4f 결과 후): 계획에 생성기 검증이 빠져 있어, 결과를 본 뒤 조건 모르는 Claude 에이전트 평가를 추가했다(표시 괄호를 지우고 섞음, v4와 같은 기준표에 가장 이상한 구간을 옮겨 적게 함). 평가자가 확인한 답변만으로 위치 맞히기를 다시 계산한 것도 추가 분석이다.

## v4g 계획: 생성 모델 효과 분리 (2026-10-28, 생성 전 작성)

04에서 두 세트의 차이를 '생성 모델 효과'로 보고했지만, 두 세트는 생성 모델, 가상 인물, 질문이 모두 달랐다. 이를 가르기 위해 v4(Claude)와 같은 인물과 같은 질문 6개로 GPT-4.1이 19개 조건을 다시 쓴다(114개, v4b와 같은 지시문, temperature 0.9).

- 평가: GPT-4.1 블라인드 평가(v4, v4b와 같은 평가자, 같은 기준표).
- 비교: 사고장애 없는 발화(N0, NMULTI, CIRC1, CIRC2)에서 지표의 Cohen's d를 두 가지로 나눈다. ① 생성 모델 효과 = 새 세트(GPT, 인물 A) 대 v4(Claude, 인물 A) ② 인물과 질문 효과 = 새 세트(GPT, 인물 A) 대 v4b(GPT, 인물 B). 지표별로 어느 쪽이 큰지 보고, 04의 결론을 이에 맞게 고친다.
- 생성기 검증 기준은 v4와 같다. 새 세트에서 단계 순서가 재현되는지도 함께 보고한다.

## 계산 점검 후 수정 (2026-10-28)

별도 점검에서 찾은 문제를 고치고 01~08을 다시 계산했다.

- TF-IDF 이탈 지표를 앞 100토큰이 아니라 답변 전체로 계산했다(팀 노트북 기본 설정과 같음). 앞 100토큰이면 창이 4개뿐이라 지표가 거의 고정값이 됐다.
- 문장 응집성을 앞 100단어가 아니라 답변 전체 문장으로 계산하고, 조건별 계산 개수를 표시했다. 문장이 3개 미만이면 여전히 계산되지 않는다.
- 04 교차 예측에서 지표 묶음마다 다른 항목으로 평가하던 것을 같은 항목으로 맞췄다. Cohen's d는 표본 수로 가중한 합동 표준편차로 바꿨다.
- 03 조합 지표를 계획대로 새 발화 전체 기준으로 표준화했고, 특이도 기준값 표시를 실제 계산(탈선 2단계)에 맞췄다. 판정은 같다.
- 05 질문 기준 거리의 실제 계산 개수를 표시하고, GPT 세트 기준값에서 생성기 검증에서 탈락한 주제 이탈을 뺐다.
- 06 되물음 판정 규칙이 맞장구("I know what you mean")와 사과("sorry to hear")를 되물음으로 세던 것을 고쳤다. 실제 되물음은 4~5개뿐이다. 같은 규칙을 쓴 v2 E5와 v3 M4도 다시 계산했고, README의 "되물음 10명 중 8명" 결과는 무효가 됐다.
- 06에서 축약형 잔여물과 말버릇(im, dont, like, yeah 등)을 내용어에서 뺐다. 의미 밀도의 반대 방향 결과가 사라졌다. 질문 내용어 5개 이하인 답변만 쓴 확인도 추가했다.
- 07의 사고장애 5종 합계 검정에서 같은 정상 답변을 다섯 번 쓰던 것을 질문·회차별 평균으로 바꿨다.
- 01 음향 연상 전용 지표 행에 생성기 검증 탈락을 표시하고, 특이도 기준값(탈선 2단계와 주제 이탈 2단계의 평균)을 본문에 그대로 적었다.

## v4h 계획: 지리멸렬용 언어모델 놀람도 (2026-11-07, 계산 전 작성)

지금까지 지리멸렬을 두 생성 모델에서 함께 잡는 지표가 없었다. Gutiérrez 등(2025, Schizophrenia Bulletin)이 느슨한 연상 탐지에 쓴 단어 놀람도(surprisal)를 추가한다.

- 계산: GPT-2(small)로 답변의 각 토큰이 앞 문맥에서 얼마나 예상 밖인지(−log 확률, 비트). 답변 전체 평균(surp_mean)과 상위 10% 토큰 평균(surp_p90, 일부 구간만 이상한 경우용).
- 자료: 같은 인물과 질문으로 만든 두 세트(Claude v4 114개, GPT-4.1 v4g 114개), 참고로 v4b.
- 판정 (두 세트 각각): ① 지리멸렬 조건 + N0에서 의도한 단계와 Spearman ρ ≥ 0.4 ② 블라인드 평가의 지리멸렬 점수와 ρ ≥ 0.3 ③ 대조 구분: NMULTI, CIRC1, CIRC2 평균이 INC2 평균보다 낮음. 두 세트 모두에서 ①과 ②를 만족하면 "지리멸렬 지표로 작동".
- 함께 보고: 다른 사고장애 종류와의 ρ(음향 연상은 낯선 단어 때문에, 보속은 반복 때문에 놀람도가 움직일 수 있음).

| 조작 | 바뀌어야 할 지표 (방향) | 그대로여야 할 지표 |
| --- | --- | --- |
| 문장 순서 무작위 | surp_mean ↑ | elv_mean, mattr, clang_rate |
| 한 문장을 세 번 반복 삽입 | mattr ↓, surp_mean ↓ | elv_mean, clang_rate |
| 다른 질문의 정상 답변으로 교체 | elv_mean ↓ | surp_mean, mattr, clang_rate |
| 전사 형식 (소문자, 문장부호 제거) | 없음 | 모두 |

- 기준 효과: 지표마다 자기 담당 유형의 2단계와 N0의 평균 차이(elv_mean은 TAN2, surp_mean은 INC2, mattr는 PER2, clang_rate는 CLANG2).
- 바뀜: 12개 중 10개 이상이 예상 방향이고 평균 변화가 기준 효과의 25% 이상. 그대로: 평균 변화가 기준 효과의 25% 미만.
- 전사 형식에서는 지리멸렬 단계와 surp_mean의 ρ(v4h 판정 ①, ρ ≥ 0.4)도 다시 본다. DAIS-C 전사에는 문장부호가 없기 때문이다.

**B. 미묘한 발화(v4f) 놀람도.** 지리멸렬 16쌍에서 surp_p90이 짝지은 정상 답변보다 높은 쌍의 수(부호 검정). 15토큰 창 평균 놀람도가 가장 높은 창이 표시 구간과 겹치는 비율과 우연 수준(이항 검정). 다른 유형은 참고로 보고한다.

**C. DAIS-C 놀람도.** 원본 대화 파일에서 답변 전체 문장을 다시 꺼내 말버릇(erm 등)을 빼고, 30단어 이상인 답변에 surp_mean, surp_p90을 계산한다. ① 같은 사람 안 DT 표시 답변 대 일반 답변(부호 검정, 길이 보정 포함) ② 환자군 대 대조군 화자 평균(참고). DT는 임상 판정이 아니므로(06) 결과가 없어도 지표 실패로 해석하지 않는다.

## v4j 계획: 말 빈곤 지표와 지표 세트 고정 (2026-11-08, 생성 전 작성)

페르소나 모델에 음성 증상을 넣으려면 그것을 재는 지표가 먼저 있어야 한다.

**A. 말 빈곤 발화 생성.** GPT-4.1, v4g와 같은 인물·질문(Q01~Q06)·지시문. TLC 정의로 두 조건을 1~3단계로 만든다(36개). 단어 수는 지시하지 않는다(지시하면 단어 수 지표가 당연히 맞게 된다).
- POV(poverty of speech, 말의 빈곤): 자발적인 말의 양이 줄어 답이 짧고 덧붙임이 없음. 150~170단어 길이 지시는 뺀다.
- POVC(poverty of content of speech, 내용 빈곤): 길이는 충분하지만 모호하거나 지나치게 추상적·상투적이고 반복이 많아 전달되는 정보가 적음. 길이 지시는 유지.

**블라인드 평가.** 새 36개와 v4g 114개를 섞어, 조건을 가린 GPT-4.1이 말의 빈곤과 내용 빈곤을 0~3점으로 평가한다(v4 평가표와 같은 형식).

**지표와 판정 (계산 전 고정).**
- POV: n_words(단어 수). POV 조건 + N0에서 단계와 ρ ≤ −0.4, 블라인드 말의 빈곤 점수와 ρ ≤ −0.3.
- POVC: info_rate(서로 다른 내용어 수 / 전체 단어 수, 앞 100단어). POVC 조건 + N0에서 단계와 ρ ≤ −0.4, 블라인드 내용 빈곤 점수와 ρ ≤ −0.3, 대조 구분: NMULTI, CIRC1, CIRC2 평균이 POVC2 평균보다 높음.
- 함께 보고: 보속(PER)과의 겹침(내용 빈곤과 반복은 비슷해 보일 수 있음).

**변경 (생성 전).** OpenAI API 키가 만료되어 A의 생성은 Claude 에이전트가, 블라인드 평가는 조건을 모르는 별도 Claude 에이전트가 한다. 비교 대상도 같은 생성 모델인 Claude v4 세트의 N0, NMULTI, CIRC1, CIRC2, PER1~3(42개)으로 바꾼다. 판정 기준은 그대로다.

**변경 2 (교차 평가, 2026-11-08, 지표 결과를 본 뒤).** 말 빈곤 평가가 생성 모델 자신의 평가(Claude가 쓰고 Claude가 평가, GPT가 쓰고 GPT가 평가)라 부풀려졌을 수 있다. 사고장애 5종과 같은 원칙으로, 쓴 모델과 다른 모델이 평가한 점수를 주 결과로 바꾼다. 두 세트 모두 같은 구성(말 빈곤 36개 + 같은 생성 모델의 기존 114개, 총 150개)을 섞어 평가한다. Claude가 쓴 세트는 GPT-4.1이, GPT-4.1이 쓴 세트는 조건을 모르는 Claude 에이전트가 평가한다. 사고장애 5종의 GPT-4.1 세트(v4g)도 GPT-4.1이 직접 평가한 점수였으므로, 같은 평가표로 Claude 에이전트가 다시 평가한 점수를 주 결과로 쓴다(Claude 세트는 원래 GPT-4.1이 평가해 이미 교차 평가다). 자기 평가는 참고로 함께 보고한다. 판정 기준은 그대로다.

**B. 지표 세트 고정.** 지금까지 통과한 지표를 src/metrics.py 하나로 묶는다. 계산은 기존 스크립트와 같게 하고, Claude v4와 GPT-4.1 v4g에서 기존 값과 일치하는지 확인한다. 유형별 담당 지표와 예상 방향, 비교 방법(같은 자료의 정상 답변 기준으로 표준화)을 여기 고정한다. 페르소나 모델 평가는 이 세트로만 한다.
