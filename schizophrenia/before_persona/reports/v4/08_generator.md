## 3. 같은 인물, 같은 질문의 두 세트(CA, GA)에서 모두 작동하는 지표

두 세트에서 방향이 같고 둘 다 ρ 절댓값 0.3 이상:

- overall_disorganization: anchor_first, anchor_mean, elv_mean, stop_ratio, mean_wlen
- tangentiality: drift_mean, anchor_first, anchor_mean, elv_mean, end_sim, stop_ratio, mean_wlen
- derailment: sem_density, anchor_mean, elv_mean
- incoherence: 없음
- perseveration: mattr, coh1_mean, coh1_min, coh2_mean, stop_ratio, mean_wlen, comma_rate
- clanging: clang_rate, semantic_drift_slope, stop_ratio, comma_rate

## 4. 해석

- **생성 모델 효과는 실제로 있다.** 인물과 질문을 맞춰도 GPT 답변은 Claude 답변보다 질문에 붙어서 답하고(elv_mean d = 0.42), 기능어와 쉼표가 많고 단어가 짧았다(stop_ratio 0.79, mean_wlen -0.89). 이 지표들에서는 인물과 질문의 차이보다 생성 모델 차이가 컸다.
- **하지만 04의 "생성 모델 효과가 사고장애 효과보다 크다"는 과장이었다.** 같은 인물과 질문으로 만든 GA 안에서는 사고장애 효과(elv_mean d = -1.12)가 생성 모델 효과보다 컸다. 생성 모델 효과가 사고장애 효과보다 큰 지표는 4개(drift_slope, rare_rate, elv_slope, punct_rate)로, 대부분 원래 사고장애를 잘 따르지 않던 지표다. 04의 비교는 사고장애 단계가 제대로 나뉘지 않은 v4b를 기준으로 해서 사고장애 효과가 작게 잡혔다.
- **인물과 질문을 맞추면 두 생성 모델에서 함께 작동하는 지표가 늘었다.** 특히 주제 이탈은 질문 기준 지표, 답변 끝 유사도, 문체 지표가 모두 두 세트에서 작동했다. 지리멸렬은 여전히 함께 작동하는 지표가 없다.
- GPT-4.1은 같은 지시문에서도 사고장애를 약하게 썼다(ρ = 0.61, 탈선 3단계 평균 1.17점). 보속은 단계 순서가 나오지 않았다.
