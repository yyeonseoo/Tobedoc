# 팀 자료에서의 전환 판독: 탐색적 분석 고정안 (2026-11-08)
기존 228개 중 N0(기본), NMULTI(관련된 여러 주제), DER2(중간 수준 전환 지시)만 사용한다. 강도를 보고 고르지 않고 양 극단을 피한 중간 수준을 택한다. 시범 수정은 1단계였고 두 질문의 ID를 모른다. 앞서 기준 조정에 사용한 Q03 전체를 제외하고 나머지 5개 질문 × 3조건 × 2출처 전부를 읽는다. 소스별 각 질문당 한 출력이다. 이전 연구에서 이 자료의 일부 원문을 접했으므로 새 독립 자료는 아니다.

1. 고정 기준 share/main-comparison-v01/AI판독기준_v1.md의 A/B/C를 사용한다. 질문과 원문만 무작위처럼 섞인 ID 순으로 읽고 사람 판정과 구분한다. B 있음·불확실은 인접 원문 쌍과 이유를 저장한다. B 없음에 인용한 예시는 전체 발화를 대신하지 않는다. 판정을 먼저 커밋하고 조건을 결합한다.
2. 주 비교는 출처별 동일 질문 DER2−NMULTI(화제 수 증가만으로도 생기는 변화인지 대조). 보조는 DER2−N0. 긍정/부정이 양쪽 모두 확정된 쌍의 차이, 전체 5쌍 중 양의 차이가 확정된 수, 전체 분모에서 불확실을 양쪽 가능성으로 둔 차이 범위를 제시한다. 판정불가도 미상, 0 대입 금지. A와 C는 별도로 보고한다. 단 한 번의 합성 표본: 유의성·임상 검증·모델 순위를 주장하지 않는다.
