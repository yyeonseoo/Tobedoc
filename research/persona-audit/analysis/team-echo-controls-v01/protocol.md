# 단어 되받기의 특이성 점검 · 2026-11-08
잠정 기전: 지난 분석에서 Claude DER2의 단어 되받기가 많았다. 같은 현상이 우회·반복 지시에서도 생기는가? 기존 스크립트 team_transition_echo.py의 get 함수(73a5923 버전)를 그대로 사용한다. 이는 공백 단어 수준이 아니라 문장부호 경계 양쪽의 마지막/처음 4개 영문 토큰 중 같은 길이 3 이상 비제외어가 있는지 세는 규칙이다. 발화별 비율=해당 경계 수/유효 경계 수. 분모 0은 미정, 0 대입 금지.

- 같은 다섯 질문(Q01,Q02,Q04,Q05,Q06), 같은 출처 내 비교. Q03 제외. N0, NMULTI, CIRC2, DER1~3, PER1~3: 9조건×5질문×2출처=90개, 이전 분석 30개 포함. 새 환자·미사용 독립 확인 표본으로 보지 않는다.
- 주 대조: 동일 단계 DER2−PER2와 DER2−CIRC2. 질문별 비율 차이(%p), 중앙값, 승/동/패, 분모와 미정 수를 공개. NMULTI를 기준으로 각각의 상승도 확인한다. PER2가 DER2보다 낮더라도 PER2에서 NMULTI보다 반복이 늘면 '탈선에만 존재하는 특징'으로 해석하지 않는다. 반대로 PER2가 더 클 때 탈선 여부를 이 점수 하나로 식별할 수 있다고 주장하지 않는다. 원래 임상 레이블이 없으므로 진단 특이도는 산출하지 않는다.
- 보조: DER/PER 단계별로 매 질문 1<2<3 엄격 증가, 동률 포함 비감소를 따로 집계한다. 단계는 지시 세기이며 관측 임상 중증도가 아니다. 단계 1에 대한 Claude 시범 수정의 질문 ID는 불명이다. 3단계 PER와 DER를 직접 비교해 중간 단계만의 현상인지 확인한다. 임계값·유의성 검정·조건 전체 순위는 도출하지 않는다.
- 사례 제시: 각 출처에서 PER2−DER2의 질문별 차이가 그 중앙값에 가장 가까운 질문(동률 Q번호 우선)을 보고한다. 인용은 해당 발화의 첫 검출 경계 또는 검출 없음. 우회 응답에 검출이 있으면 첫 사례를 명시한다. 실제 문맥과 중복 단어는 원문에서 검산한다. 이 분석은 기존 판독 기준·전문가 표본 계획을 수정하지 않는다.
