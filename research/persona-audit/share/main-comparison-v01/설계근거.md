# 본 실험 선택의 근거와 제외한 대안

## 기존 분석이 결정에 주는 근거

팀의 228개는 TLC 유형별 합성 발화이며 PSYCHE·PSI·PatientSim의 동등 실행 결과가 아니다. 반복률은 보속형 문자 반복에 반응했지만 INC3의 MATTR 반대 방향은 단어 구성에 좌우됐다. 따라서 이를 임상적 주 평가 점수로 올리지 않는다. 본 실험은 최신 로드맵의 질문 관련성·발화 내부 연결 축으로 돌아가며, 이번 직접 특징 분석은 혼동 요인과 보조 기술값을 지정하는 근거로 사용한다.

기존 48응답의 저장 벡터와 원문 해시를 확인하고 인접 코사인·전체 문장쌍 평균·차이 값을 독립적으로 다시 계산했다. 같은 단어/문장 수의 관련 문장 대 다른 사건 문장 삽입 48쌍도 저장 벡터로 재계산했다. 다른 사건 삽입에서 인접 코사인이 오히려 더 높은 경우는 20/48쌍이었다. 이것은 지시문을 어느 모델이 더 잘 따르는지 판단하는 데 점수 하나만 사용하면 안 되는 구체적 근거다. 모든 의미 임베딩의 무효를 입증하지는 않는다.

별도 저장 분석에서 일반 요약 1,542개의 해당 인접 코사인과 전문가 coherence 평가는 Spearman 0.0317이었다. 이번에는 그 전체 코퍼스를 재분석하지 않고 결과 파일과 해시를 확인했다. 임상 환자 자료의 외적 검증으로 확대하지 않는다.

## 기존 코드에서 재사용할 것

- NativeFeatures.swift: 영어 OS sentence embedding revision 1, 512차원 및 원문 UTF-16 위치. 새로운 모델로 조용히 대체하지 않는다. 이번에는 새 임베딩을 계산하지 않았다.
- extract_automatic_features.py의 question_answer_cos: 실제 질문 문장 벡터 중심과 답변 문장 벡터 중심 사이 코사인이다. 문장 중심값이라 문장 분절의 영향을 받는다. 답변 정확성은 아니다.
- topic_local_separation.py의 topic_association: 답변 문장별로 고정 사건 prototype과의 최대 유사도를 구해 평균한다. 실제 질문-답변 코사인과 다르므로 명칭을 섞지 않는다.
- 인접 코사인과 adjacency_excess: 문장 집합·배열을 기술하는 보조값. 역순 배열 불변성은 수학적 성질이며 새로운 임상 실패 발견이 아니다. 두 문장에서는 excess가 0이다.
- 요청 사실 alias: 사실 언급 후보 추출에만 쓴다. 부정·다른 사건 귀속·모순을 판정하는 정답으로 쓰지 않고, 생성 전에 고정한 사실 목록에 원문 근거를 연결한다.

## 표적 문헌 확인

1. [Andreasen의 TLC 원저](https://cssh.northeastern.edu/cali/wp-content/uploads/sites/57/2022/09/Scale-for-the-assessment-of-thought-language-and-communication.pdf), PDF 4~5쪽 항목 5~7: 질문에 대한 비껴간 응답, 절·문장 사이 전환, 절 내부 이해 곤란을 구분하는 근거다. 면담 빈도에 기반한 점수를 단일 생성 답변에 그대로 옮기지 않는다. 이 실험의 평가는 원척도를 검증하거나 대체하지 않는 연구용 관찰이다.
2. [PSYCHE 원저 v1](https://arxiv.org/html/2501.01594v1), MFC-Behavior 및 Table 11~12: 행동 필드와 구체 지시/예시를 통한 사고과정 구현 접근이 이미 있다. 그러므로 ‘구체 지시를 넣었다’ 자체를 새로움으로 주장하지 않는다. 여기서는 제한된 로컬 적용판에서 목표 변화·문체·부작용을 통제 비교한다. 원저의 전문가 검증을 현재 적용판이 물려받는다고 보지 않는다.
3. [He et al., 2026](https://pubmed.ncbi.nlm.nih.gov/41656336/), 초록 확인: 의미 유사도와 사람의 coherence 판단이 일치하지 않을 수 있음을 보고한다. 이 결과와 로컬 실패 대조는 코사인을 주 판정에서 제외하는 근거다. 논문의 확률 기반 지표가 우리 자료에서도 적절하다고 추정하거나 새 지표·모델 탐색을 시작하지 않는다.

확인일 2026-11-04. 표적 근거 점검이며 체계적 문헌고찰이나 최초성 검증이 아니다. 코드 원형은 PSYCHE 저자 공식 구현이 아닌 PatientHub의 고정 commit 54d5c8761a9055a1e86d153715607ef9fa26358a를 참고한 로컬 적용판이다.

## 사용자 평가와 검증의 경계

사용자가 단독 검토 가능하다고 답했으므로 사람 검토를 임상 전문가 확보와 동일시하지 않는다. 16개는 기준을 맞추는 개발 자료다. 같은 사람이 생성 조건을 모른 채 평가하더라도 원문을 이미 봤을 수 있고 문체에서 출처를 추정할 수 있다. 인지 여부를 기록하고 이후 보고한다. 단독 평가의 재현성 한계를 명시하며 독립 평가자 간 일치도를 주장하지 않는다.

2×2의 주 효과는 ‘구체 지시의 효과가 DER에서 Normal보다 큰가’를 묻는다. 이 상호작용만으로 DER 발화의 질이 좋아졌다고 결론낼 수는 없다. 각 셀의 결과와 길이·질문 답변성·절 내부 이해·사실 모순을 함께 제시한다. C0/C5 대조에서 목표로 분류된 사례도 숨기지 않으며, 라벨을 맞히도록 평가 규칙을 수정하지 않는다.

기존 PSYCHE 개발16개는 동일 출력이 아닌 것과 길이 준수만 확인됐으며 목표 전환은 아직 사람 평가되지 않았다. 기존 미생성32개는 새로운 6조건 설계와 같지 않아 자동 실행하지 않는다. 기존16개를 재사용하려면 모델·template·옵션·공통 프롬프트가 같아야 하며, 달라지면 과거 자료는 별도 개발 자료로만 둔다.
