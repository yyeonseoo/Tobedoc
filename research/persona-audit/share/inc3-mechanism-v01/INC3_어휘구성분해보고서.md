# INC3 어휘 다양성 반대 방향의 원인 분해

2026-11-04 · 로드맵 1단계 내 두 번째 탐색 · 새 발화 생성 0개

**이 자료에서 반대 방향을 만든 주된 수치 성분은 기능어 목록에 속한 단어의 반복이었다.** Claude INC3에서는 소수의 기능어를 거듭 사용해 MATTR50이 낮아졌다. GPT-4.1 INC3에서는 기능어 비중이 크게 낮아져 해당 반복 성분이 줄었고, 그 결과 전체 MATTR50이 높아졌다. “GPT가 더 다양한 내용어를 생성했다”는 단순 해석은 지지되지 않는다. 기능어 목록 외 단어만 비교하면 두 자료 모두 변화가 작고 비슷했다.

이것은 고정된 지표의 산술 분해와 삭제 민감도 분석이다. 인과적 생성 메커니즘, 내용어의 의미적 다양성, 문법 파괴 정도 또는 임상적 사고장애를 검증한 결과는 아니다.

## 분석 범위와 고정 규칙

기존 228개 중 N0, NMULTI, CIRC1, CIRC2, INC1, INC2, INC3, PER3의 96개를 사용했다(2생성 방식 × 6질문 × 8조건). 주 비교는 같은 질문 안의 INC3−N0 6쌍씩이다. 앞 단계 결과를 본 뒤 선택한 사후 설명 분석이며, 이번 분해 결과를 계산하기 전 규칙을 Git commit be91e8a에 고정했다. 별도 검증 표본은 없다.

품사 분석기나 LLM 판정을 수치 계산에 쓰지 않았다. 명시적 기능어 목록과 축약형을 합친 목록을 주 분석에, 축약형 추가 전 목록을 민감도 분석에 썼다. 정확한 목록은 config/inc3-mechanism-v01.json에 있다. 이 목록은 대명사·전치사·관사·보조동사뿐 아니라 일부 부사·수량어도 포함하는 조작적 분류다. 동형어·have/do의 본동사 용법·축약형의 문맥별 역할을 구분하지 않으므로 목록 밖 단어를 모두 내용어로 단정하지 않는다.

원래의 모든 연속 50단어 창을 그대로 유지하여 다음 항등식으로 분해했다.

**MATTR50 = 1 − 기능어 목록 반복 손실 − 목록 외 반복 손실**

각 손실 = (해당 범주의 총 토큰 수 − 해당 범주의 서로 다른 단어 수) / 50. 같은 창에서 계산한 뒤 창 전체를 평균한다. 따라서 두 손실의 변화에 마이너스를 붙이면 전체 MATTR 변화와 정확히 일치한다. 수치상 기여도를 특정할 수 있지만, 그 성분과 MATTR의 상관을 독립적인 발견으로 제시하지 않는다.

아래 값은 INC3−N0의 질문별 차이를 평균한 값이다. 대괄호는 6개 질문의 모든 6^6 재표집에서 얻은 기술적 95% percentile 구간이다. 손실의 양수는 반복 증가, 즉 MATTR를 낮추는 방향이다.

|---|---:|---:|---:|
| Claude | -0.2380 [-0.2684, -0.2071] | +0.2391 [+0.2025, +0.2728] | -0.0011 [-0.0075, +0.0053] |

Claude: −0.2380 = −0.2391 + 0.0011. 감소가 기능어 목록의 반복 손실 증가로 거의 전부 설명된다. 목록 외 반복 손실 변화는 거의 0이다. 기능어 반복 손실 증가는 6/6 질문에서 나타났다.

GPT-4.1: +0.0575 = +0.0699 − 0.0124. 기능어 목록의 반복 손실 감소가 전체 다양성 증가를 만들었고 목록 외 반복 손실은 오히려 증가하여 이를 일부 상쇄했다. 기능어 반복 손실 감소는 5/6 질문에서 나타났다. 이는 “내용어 중복이 줄어서 전체 다양성이 올랐다”는 설명과 다르다.

## 단어 비중과 삭제 민감도

| 생성 방식 | 기능어 목록 비중 N0→INC3 | 비중 차이 | 목록 제거 후 MATTR25 차이 [95% 구간] |
|---|---:|---:|---:|
| Claude | 55.68% → 49.28% | -6.39%p | +0.0093 [-0.0028, +0.0225] |
| GPT-4.1 | 55.86% → 25.22% | -30.64%p | +0.0092 [-0.0094, +0.0227] |

Claude에서도 기능어 비중 자체는 감소했다. 따라서 “기능어를 더 많이 넣어서 다양성이 낮아졌다”는 설명은 부정확하다. 양이 늘어난 것이 아니라 일부 기능어에 반복이 집중된 양상이다. GPT-4.1은 기능어 목록의 비중이 약 56%에서 25%로 줄어 문법적 연결 표현이 적은 단어 나열 쪽으로 이동했다.

목록을 제거한 뒤 남은 단어의 연속 25단어 창을 비교하면 두 자료의 변화는 모두 약 +0.009였다. 두 구간 모두 0을 포함한다. 삭제 후 25단어 창과 원래 50단어 창은 서로 다른 측정이므로 “몇 %의 효과를 제거했다”는 비율을 계산하지 않았다. N0와 INC3의 목록 외 MATTR25 평균이 약 .976~.988로 상한 1에 가까워, 작은 차이는 천장효과의 영향을 받을 수 있다. 남은 단어들의 의미가 잘 연결되거나 두 자료의 내용어 다양성이 동등함을 입증하지 않는다.

## Ollama 사용과 검증

로컬 qwen3:14b에 N0·INC3 24개를 질문별 4개씩, 총 6회로 나눠 짧은 언어적 관찰과 원문 근거 구절을 요청했다. 입력 5,914·출력 2,460토큰을 로컬에서 처리했다. 생성기·조건·수치 결과를 숨기고 불투명 ID와 고정 해시 순서를 사용했다. 스타일을 보고 출처를 짐작할 가능성까지 차단한 것은 아니다.

반환된 24개 항목의 인용 48개 중 원문 연속 부분문자열 검사를 통과하지 못한 인용은 2개, 5~18단어 길이 지시를 벗어난 인용은 20개, ID/파싱 오류는 0개, 정상 종료가 아닌 항목은 0개다. 정확한 인용이라는 사실이 해석의 정확성까지 보증하지는 않는다. Qwen은 특징 계산·임상 채점·정답 생성에 사용하지 않았다. 관찰 원문과 인용 검사는 analysis/inc3-mechanism-v01/local-review/audit.json에 보존했고, 설명용 보조 자료로만 취급했다.

Qwen은 일부 서로 다른 발화에 동일한 “frequent repetition” 문구를 적용했고 Claude Q03·Q04에는 “minimal connecting words”라고 서술했다. 그러나 제시한 원문에는 the/of의 반복이 뚜렷하여, 연결 의미와 기능어 빈도를 구별한 설명으로 충분하지 않았다. 본 보고서는 이 표현을 정답으로 채택하지 않았다. 로컬 모델은 원문 검토용 발췌·초벌 메모에 활용하고, 핵심 주장에는 실제 빈도와 정확한 분해 계산을 사용했다.

## 보고서에 추가할 결론과 다음 경계

“INC3 조건의 생성 절차별 MATTR 반대 방향을 고정된 단어 목록으로 분해한 결과, Claude에서는 목록 내 단어 반복 증가가 전체 감소를 설명했고 GPT-4.1에서는 목록 내 반복 감소가 전체 증가를 설명했다. 목록 외 단어의 고정 창 다양성 변화는 두 절차에서 작았다. 이 자료에서 전체 어휘 다양성은 지리멸렬의 공통 강도보다 생성된 문장의 어휘 구성에 민감했다.”

이번 분석은 기존 결과의 설명력을 높였지만, 단일 인물·6질문·출력당 반복 없음·Claude의 평가 피드백·API/대화 생성 차이와 교락이라는 한계는 그대로다. bootstrap 구간은 질문 사이의 기술적 변동성만 표현한다. 새로운 유의성 검정을 추가하지 않았고 확증적 기전 발견이라고 쓰지 않는다.

이번 한정 분석의 완료는 전체 연구 종료를 뜻하지 않는다. 사용자 제공 11월 4일 로드맵에 따라 현재는 1단계 탐색에 해당한다. 다음은 기존 의미 관련성·문장 연결 코드와 실패 대조를 점검하고 본 실험의 주 비교·평가 준거·대조·고정/조작 요소를 한 장으로 확정하는 2단계다. 이후 동일 조건 비교, 평가 가능한 실패가 있을 때의 수정, 미사용 조건 검증, 자문·팀 자료 연결을 진행한다. 논문 작성은 앞으로 약 한 달간 후속 연구를 수행한 뒤다. 새 생성은 지금 실행하지 않는다.
