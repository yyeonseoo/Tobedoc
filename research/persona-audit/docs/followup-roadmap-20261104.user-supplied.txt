특징 출처 목록, 여러 로컬 지시 비교, 측정 지표의 실패 사례, PSYCHE 개발 실험이 있다. 서로 목적이 다른 예비실험을 하나의 임상 성능으로 합치지 않는다. 기존 결과와 한계는 02번 txt, 자료와 도구는 03번 txt를 참고한다.

자료의 역할
228개 자료는 TLC 유형·중증도 조작에 대한 지표 반응을 분석할 팀 자료다. PATIENT-Ψ·PatientSim·PSYCHE 원형 시스템의 생성 결과라고 간주하지 않는다. 기존 로컬 페르소나 결과는 지시 효과·혼동 요인·구현 실패에 관한 별도 자료로 유지한다. 두 갈래는 측정 질문을 공유할 수 있지만 같은 실험처럼 합치지 않는다.

1단계. 기존 자료로 특징 비교 결과를 만든다 — 바로 할 작업
새 발화를 생성하지 않고 228개 원문과 기존 특징 코드를 연결한다. 원본을 보존하고 행 식별자·조건표·해시를 기록한다. 생성기별, 유형·단계별, 같은 질문 안의 대조를 구분한다.

계산 후보:
길이·반복 등 직접 기술값, 질문-답변 의미 연관성, 문장 간 의미 유사도. 기존 정의와 코드를 먼저 확인하고 재사용하며 임상 점수나 최적 지표를 새로 만들지 않는다. 임베딩 유사도를 임상적 연결성으로 동일시하지 않고 기존 실패 대조와 함께 해석한다. 모든 유형을 단일 유사도 점수로 평가하지 않는다.

첫 산출물:
유형·단계별 반응 그림, 정상/자연스러운 화제 전환/우원증 대조의 분포, 같은 질문의 발화 예시, 지표가 구별한 것과 구별하지 못한 것. 고정된 한 인물·여섯 질문에 대한 기술 분석임을 유지한다. 응답 228개를 독립 환자 228명으로 세지 않는다. LLM 평가표 없이 상관 0.89·0.61이나 국소 겹침 41%를 재현했다고 하지 않는다.

2단계. 본 실험의 주 비교 하나를 고정한다
원래 제안은 질문 관련성과 문장 간 연결을 주축, 길이·요청 정보 보존을 보조 축으로 보는 것이었다. 1단계는 탐색 결과이며, 그 결과와 가까운 선행연구를 근거로 후속 주 비교를 명시한다. 지표가 목표 현상과 대조를 구분하지 못하면 타당한 측정처럼 계속 쓰지 않는다.

기존 PSYCHE 중심 후보와 PSI·PatientSim 지시 비교 구상은 보존하되, 서로 다른 임상 목적의 지시를 동등한 증상으로 서열화하지 않는다. 무엇을 고정·조작하고 어떤 평가 준거로 판단할지 한 장에 확정한다. 측정 준거가 없다면 무엇이 빠졌는지와 더 좁게 답할 수 있는 질문을 먼저 제시한다. 설계안을 다시 끝없이 늘리는 단계로 만들지 않는다.

3단계. 원하는 변화와 부작용을 같은 조건에서 비교한다
필요한 주 비교가 정해지면 같은 허구 사례·질문·백엔드에서 중립 지시, 특징 이름만의 지시, 출처 기반 지시와 적절한 대조를 비교한다. 기존 응답을 우선 사용하고 부족한 조건만 제한적으로 생성한다.
질문 관련성·문장 관계·길이·정보 보존을 구분해서 보고한다. Qwen 적용판은 로컬 지시 모듈 실험이며 원형 시스템 전체의 성능 순위가 아니다. Qwen 정상 자료와 다른 모델의 목표 발화를 합쳐 분류기를 만들지 않는다.

4단계. 구체적인 실패 하나만 수정한다
생성 지시의 실패인지 측정의 실패인지 먼저 구분하고, 한 번에 한 문제를 겨냥한다. 원형 적용판과 수정판을 비교하며, 가능하면 비표적 지시 추가/제거 대조로 원인을 분리한다. 목표 변화와 부작용을 함께 평가한다.
구체적 실패와 평가 가능한 준거가 없으면 개선 단계를 생략할 수 있다. 임상적 성공을 만들기 위해 지표만 바꾸지 않는다.

5단계. 미사용 조건에서 확인하고 결론을 고정한다
검증 전 주 지표·대조·오류 처리·성공 기준을 고정한다. 같은 사례의 질문·seed만 바꾼 것을 새로운 인물 검증이라고 하지 않는다. 새로운 사례와 질문 표현을 사용하고, 다른 생성기에 일반화하려면 별도 확인이 필요하다.
한 번 고정한 검증 배치까지 평가하면 효과 유지·부작용·비재현 중 실제 결과를 결론으로 남긴다. 같은 검증 자료에서 계속 수정안을 탐색하지 않는다. 기존 PSYCHE 검증용 미생성 32요청도 지금 질문에 맞는지 판단하지 않고 자동 실행하지 않는다.

6단계. 임상 자문과 팀 자료를 연결해 마무리한다
교수 자문은 대표 원문·반례·임상 개념 대응에 집중한다. 전문의 대량 채점의 부재가 모든 합성 자료 분석을 막지는 않지만 임상 타당도를 대신했다고 하지 않는다.
블라인드 평가표·참조 구간·코드를 받으면 해당 보고값을 별도 재검산한다. 국소 탐지 41%는 검증 후보이지 미리 정한 주성과가 아니다.
최종 산출물은 특징 지도, 비교 그림과 원문 예시, 가능한 경우 수정 전후 검증, 재현 코드·조건표와 한국어 2~3쪽 보고서다.

자원·기록 원칙
파싱·특징 추출·통계·시각화는 로컬 코드, 중요한 설계·해석은 assistant가 맡는다. 새 유료 API·모델 다운로드·설치·원격 작업은 자동 시작하지 않는다. 모델 설치가 임상 평가 능력의 근거는 아니다.
코드 작업 전 실제 Git 저장소·remote·branch·기존 변경을 확인한다. 코드·조건·분석 변경 이유·실행 및 검증 기록을 버전 관리하되 push나 자료 공개를 자동 수행하지 않는다. 민감 자료·대형 캐시·비밀키는 올리지 않는다.

새 대화의 첫 과제
이 로드맵과 인계 자료를 읽고, 연구 배경 조사나 새 생성부터 다시 시작하지 말 것. 먼저 1단계에서 기존 코드로 계산할 항목과 산출물을 짧게 밝힌 다음 실제 비교 분석으로 진행한다. 처음 결과를 보고한 뒤 2단계의 주 비교를 확정한다. 이 인계 문서 작성 자체는 1단계 분석을 완료한 것이 아니다.
